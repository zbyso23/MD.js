MDJS ULTRA - XT / 286 DEV DISK 4M.1
===================================
A: FreeDOS (RO), B: developer tools (RO), both auto-mounted.
The same B: image works in XT 8086 and AT/286.

FIRST: select "Pracovni kopie B: (RW)" in PC Workbench.
This keeps the built-in ORIGINAL read-only. Export your work IMG.

C WORKFLOW (XT AND AT/286):
 B:
 EDIT HELLO.C
 CC HELLO
 ASM HELLO
 YLINK HELLO.OBJ,CLIB.LIB -e=HELLOC.EXE
 HELLOC
 Expected: Hello from 16-bit DOS C!

NOTE: CC HELLO generates HELLO.ASM, ASM HELLO generates
HELLO.OBJ and YLINK produces HELLOC.EXE.

TOOLS: EDIT.COM / DEBUG.COM / CC.EXE / ASM.EXE / YLINK.EXE
       CLIB.LIB / STDIO.H

NASM is NOT included. No new CPU instructions were added.
Read NOTICE.TXT for redistribution information.
A:/B: are write-protected by default; export writable copies.

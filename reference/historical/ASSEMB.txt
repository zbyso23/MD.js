                       1.1. Registry procesoru 8086/8088
                       ---------------------------------
  +----> 15 ............... 0
  |       7 ..... 0 7 ..... 0
+-+-----------^---------^---+
| AX    =    AH    +   AL   | akumulátor          --+ hlavní registry
| BX    =    BH    +   BL   | bázový registr        |
| CX    =    CH    +   CL   | čítací registr        |
| DX    =    DH    +   DL   | datový registr      --+
+---------------------------+
|            SP             | ukazatel zásobníku  --+ ukazatele
|            BP             | bázový ukazatel     --+
+---------------------------+
|            SI             | zdrojový index      --+ indexy
|            DI             | cílový index        --+
+---------------------------+
|            IP             | ukazatel instrukcí  --+ řízení programu
|          FLAGS            | registr příznaků    --+
+---------------------------+
|            CS             | kódový segment      --+ segmentové registry
|            DS             | datový segment        |
|            SS             | segment zásobníku     |
|            ES             | zvláštní segment    --+
+---------------------------+

                             1.2. Registr příznaků
                             ---------------------

 bit  0: CF přenos ........ nastaví se při přetečení aritmetické operace

 bit  2: PF parita ........ nastaví se při sudém počtu bitů 1 po aritm. operaci

 bit  4: AF pomocný přenos  nastaví se při přenosu z nižší poloviny operandu

 bit  6: ZF příznak nuly .. nastaví se, je-li výsledkem operace nula (shoda)

 bit  7: SF znaménko ...... odpovídá nejvyššímu bitu výsledku (1=záporný)

 bit  8: TF krokování ..... při nastavení každá instrukce vyvolá přerušení INT3

 bit  9: IF přerušení ..... při nastavení je povoleno přerušení (kromě NMI)

 bit 10: DF směr .......... při nastavení se ukazatele snižují, při 0 zvyšují

 bit 11: OF přeplnění ..... nastaví se při přetečení operace se znaménkem





                         1.3. Adresace paměti, operandy
                         ------------------------------
Paměť  se  adresuje  pomocí  20 bitů - tj. lze adresovat 1 MB paměti. Absolutní
adresa vznikne součtem segmentového registru * 16 s offsetovým registrem:

      segmentový registr (např. DS):  xxxx xxxx xxxx xxxx .... (16 bitů)
      offset        (např. SI + BX):  .... yyyy yyyy yyyy yyyy (16 bitů)
                                      ------------------------
      absolutní adresa                xxxx zzzz zzzz zzzz yyyy (20 bitů)

- konstanta (číslo 8 nebo 16 bitů)
- registr Al,BL,CL,DL, AH,BH,CH,DH, AX,BX,CX,DX, SP,BP, SI,DI, CS,DS,SS,ES
- index        [SI],    [SI+offset],    [SI+návěští],    implicitní segm. DS
- index        [DI],    [DI+offset],    [DI+návěští],    implicitní segm. DS
- báze         [BX],    [BX+offset],    [BX+návěští],    implicitní segm. DS
- báze         [BP],    [BP+offset],    [BP+návěští],    implicitní segm. SS !
- báze + index [BX+SI], [BX+SI+offset], [BX+SI+návěští], implicitní segm. DS
- báze + index [BX+DI], [BX+SI+offset], [BX+SI+návěští], implicitní segm. DS
- báze + index [BP+SI], [BP+SI+offset], [BP+SI+návěští], implicitní segm. SS !
- báze + index [BP+DI], [BP+SI+offset], [BP+SI+návěští], implicitní segm. SS !
- řetězová instrukce     zdroj DS:SI,  příjemce ES:DI

Varování: U  AT  se  nesmí  adresovat  slovo na přelomu segmentů (tj. nesmí být
          offset adresy slova = 0FFFFh) - vyvolá přerušení INT 0Dh a zamrzne !

                            1.4. Aritmetické operace
                            ------------------------
 Nekovaná čísla BCD (v AL nižší číslice 0 až 9, v AH vyšší číslice 0 až 9):
AAA      - ASCII korekce po součtu BCD (AH <- 1. číslice, AL <- 2. číslice)
AAS      - ASCII korekce po odečítání (AH <- 1. číslice, AL <- 2. číslice)
AAD      - ASCII korekce před dělením BCD (AL <- AH*10+AL, AH <- 0)
AAM      - ASCII korekce po násobení BCD (AH <- AL/10, AL <- AL MOD 10)

 Pakovaná čísla BCD (v nižší tetrádě AL nižší číslice, ve vyšší tetrádě vyšší)
DAA      - dekadická korekce po součtu (AL_H <- 1. číslice, AL_L <- 2. číslice)
DAS      - dekadická korekce po odečítání (AL_H <-1.číslice, AL_L <-2.číslice)

ADD      - aritmetický součet
ADC      - aritmetický součet s přičtením příznaku přenosu CF
SUB      - aritmetický rozdíl
SBB      - aritmetický rozdíl s odečtením příznaku přenosu CF
CMP      - porovnání dvou operandů (příznaky přenosu jako při operaci SUB)
NEG      - negace operandu
INC      - inkrementace (zvýšení o 1) - pozor, neovlivní příznak CF !
DEC      - dekrementace (snížení o 1) - pozor, neovlivní příznak CF !

DIV      - dělení bez znaménka (AX/op->AL,AH=zbytek) (DX:AX/op->AX,DX=zbytek)
IDIV     - dělení se znaménkem (AX/op->AL,AH=zbytek) (DX:AX/op->AX,DX=zbytek)
MUL      - násobení bez znaménka (AL*op->AX) (AX*op->DX:AX) (neplatí příznaky!)
IMUL     - násobení se znaménkem (AL*op->AX) (AX*op->DX:AX) (neplatí příznaky!)

                          1.5. Logické operace, rotace
                          ----------------------------
AND      - logické AND
OR       - logické OR
XOR      - logické XOR (používá se pro nulování registrů - XOR BX,BX)
NOT      - logická inverze operandu
TEST     - test operandu 1 operandem 2 (nastaví příznaky jako AND)


První  operand  pro  rotace může být libovolný kromě segmentů, druhý operand je
číslo 1 nebo registr CL a udává počet rotací.

RCL      - rotace vlevo, přes příznak CF (mění jen příznaky OF a CF)
RCR      - rotace vpravo přes příznak CF (mění jen příznaky OF a CF)
ROL      - rotace vlevo, kopie bitu 7 do příznaku CF (mění jen přízn. OF a CF)
ROR      - rotace vpravo, kopie bitu 7 do příznaku CF (mění jen přízn. OF a CF)
SAL      - aritm. posun vlevo, CF <- bit 7, bit 0 <- 0 (nastaví příznaky)
SAR      - aritm. posun vpravo, SF -> bit 7, bit 0 -> CF (nastaví příznaky)
SHL      - logický posun vlevo, CF <- bit 7, bit 0 <- 0 (nastaví příznaky)
SHR      - logický posun vpravo, 0 -> bit 7, bit 0 -> CF (nastaví příznaky)




                             1.6. Řetězcové operace
                             ----------------------
Po  provedení  každé  řetězcové  instrukce  se ukazatele posunou podle příznaku
směru  DF  nahoru  nebo  dolů.  Při  použití prefixu REP se řetězcová instrukce
opakuje CX krát (po provedení je v CX 0). Je-li CX=0, neprovede se ani jednou).
Prefix REPE se po provedení jednoho kroku opakuje pouze v případě shody operace
porovnání  (použití  při porovnání řetězců na shodu). Při použití prefixu REPNE
se operace opakuje jen při neshodě (použití při vyhledání znaku v řetězci).

CMPSB    - porovnání řetězců s velikostí bajt (význam  CMP DS:[SI],ES:[DI])
CMPSW    - porovnání řetězců s velikostí slovo (význam  CMP DS:[SI],ES:[DI])

LODSB    - načtení bajtu AL z řetězce DS:SI (význam MOV AL,DS:[SI])
LODSW    - načtení slova AX z řetězce DS:SI (význam MOV AX,DS:[SI])

MOVSB    - přesun bajtu z adresy DS:SI do adresy ES:DI
MOVSW    - přesun slova z adresy DS:SI do adresy ES:DI

SCASB    - porovnání AL s řetězcem ES:DI (význam CMP AL,ES:[DI])
SCASW    - porovnání AX s řetězcem ES:DI (význam CMP AX,ES:[DI])

STOSB    - uložení AL do adresy ES:DI (význam MOV ES:[DI],AL)
STOSW    - uložení AX do adresy ES:DI (význam MOV ES:[DI],AX)


                                   1.7. Skoky
                                   ----------
JMP      - nepodmíněný skok (typ SHORT, NEAR nebo FAR)
JA,JNBE  - skok, je-li nad = není pod ani shoda (je CF=0 a ZF=0)
JAE,JNB,JNC - skok, je-li nad nebo shoda = není pod = není přenos CF (je CF=0)
JB,JNAE,JC  - skok, je-li pod = není nad ani shoda = je přenos CF (je CF=1)
JBE,JNA  - skok, je-li pod nebo shoda = není nad (je CF=1 nebo CF=1)
JE,JZ    - skok, je-li shoda = je nula (je ZF=1)
JNE,JNZ  - skok, není-li shoda = není nula (je ZF=0)
JG,JNLE  - skok, je-li větší = není menší ani shoda (je ZF=0 a SF=OF)
JGE,JNL  - skok, je-li větší nebo shoda = není menší (je SF=OF)
JL,JNGE  - skok, je-li menší = není větší ani shoda (je SF<>OF)
JLE,JNG  - skok, je-li menší nebo shoda = není větší (je SF<>OF nebo ZF=1)
JO       - skok, je-li přetečení (je OF=1)
JNO      - skok, není-li přetečení (je OF=0)
JP,JPE   - skok, je-li parita = parita je sudá (PF=1)
JNP,JPO  - skok, není-li parita = parita je lichá (PF=0)
JS       - skok, je-li znaménko = je záporné (SF=1)
JNS      - skok, není-li znaménko = je kladné (SF=0)
JCXZ     - skok, je-li registr CX=0 (neovlivní příznaky)
LOOP     - snížení CX o 1 a skok, je-li CX<>0
LOOPE,LOOPZ - snížení CX o 1 a skok, je-li CX<>0 a zároveň je shoda/nula
LOOPNE,LOOPNZ - snížení CX o 1 a skok, je-li CX<>0 a zároveň není shoda/nula


                                1.8. Podprogramy
                                ----------------
CALL     - vyvolání podprogramu (NEAR - uloží se IP, FAR - uloží se CS a IP)
RET      - návrat z podprogramu (NEAR - návrat IP, FAR - návrat IP a CS)

INT      - vyvolání přerušení číslo 0 až 255 (uloží se FLAGS, CS a IP)
INTO     - vyvolání přerušení INT 4 v případě, že je příznak přetečení OF
IRET     - návrat z obsluhy přerušení (navrátí IP, CS a FLAGS)


                                1.9. Přesuny dat
                                ----------------
MOV      - přesun obsahu operandu 2 do operandu 1
LEA      - naplnění efektivní adresou (např. LEA AX,[BP+offset])
LDS      - naplnění registru i segmentu DS dvojslovem (např. LDS SI,[ukazatel])
LES      - naplnění registru i segmentu ES dvojslovem (např. LES DI,[ukazatel])
LAHF     - naplnění registru AH obsahem příznak. registru FLAGS - LOW
SAHF     - uložení registru AH do příznak. registru FLAGS - LOW
PUSH     - uložení slova do zásobníku (registr nebo adresa)
POP      - návrat slova ze zásobníku (registr nebo adresa, nesmí být CS)
PUSHF    - uložení registru příznaků do zásobníku
POPF     - návrat registru příznaků ze zásobníku
XCHG     - záměna dat
XLAT     - tabulkový převod (význam MOV AL,DS:[BX+AL])

                        1.10. Řídicí instrukce procesoru
                        --------------------------------
CBW      - konverze bajtu v AL na slovo v AX (s dodržením znaménka)
CWD      - konverze slova v AX na dvojslovo DX:AX (s dodržením znaménka)

CLC      - nulování příznaku přenosu CF
CMC      - doplněk příznaku přenosu CF (inverze)
STC      - nastavení příznaku přenosu CF

CLD      - nulování příznaku směru DF (bude směr nahoru)
STD      - nastavení příznaku směru DF (bude směr dolů)

CLI      - nulování příznaku přerušení (přerušení bude zakázáno)
STI      - nastavení příznaku přerušení (přerušení bude povoleno)

IN       - vstup z portu (povoleno IN AL,DX; IN AX,DX; IN AL,[n8]; IN AX,[n8])
OUT      - výstup na port (OUT DX,AL; OUT DX,AX; OUT [n8],AL; OUT [n8],AX)

ESC      - předání řízení koprocesoru
HLT,HALT - zastavení procesoru (pokračování po přerušení)
LOCK     - uzamčení sběrnice pro následující instrukci (proti přerušení a DMA)
NOP      - prázdná instrukce, nic se neprovede (jednobajtový kód 90h)
WAIT     - čekání (je-li vstup procesoru TEST aktivní)



INT 00h  - vyvolá se při chybě dělení nulou nebo při přetečení dělení
INT 01h  - vyvolá se po každé instrukci, je-li nastaven příznak krokování TF
INT 02h  - nemaskovatelné přerušení (chyba paměti, výpadek napětí) 
INT 03h  - bod přerušení programu (používá debugger - instrukce má kód 0C0h)
INT 04h  - přetečení (vyvolá se instrukcí INTO, je-li příznak přetečení OF)
INT 05h  - tisk obrazovky (vyvolá se z INT 09h stiskem klávesy PrintScreen);
           nastavuje systémový příznak na adrese 0040h:0100h (0000h:0500h): 
                     0 ...... obsluha Print Screen neprobíhá 
                     1 ...... obsluha Print Screen právě probíhá 
                     0FFh ... během poslední funkce Print Screen nastala chyba
INT 06h  - přerušení AT při nedefinovaném oper. kódu
INT 07h  - přerušení AT, není-li matem. koprocesor 
INT 08h  - přerušení od systémových hodin (IRQ 0) (18.20651 krát za sekundu);
           Čítá  čítač  (dvojslovo)  na adrese 0040h:006Ch. Po dosažení půlnoci
           (hodnota  čítače  1573040) se čítač vynuluje a nastaví se příznak na
           adrese 0040h:0070h na 1 (příznak zvýšení data) - nuluje čtením času
INT 09h  - přerušení od klávesnice (IRQ 1) - při stisku nebo uvolnění klávesy 
              0040h:001Ah  - čtecí adresa z bufferu klávesnice 
              0040h:001Ch  - ukládací adresa do bufferu klávesnice
              0040h:001Eh  - standardní buffer klávesnie (16 slov)
              0040h:0080h  - offset začátku bufferu klávesnice (segment 0040h)
              0040h:0082h  - offset konce bufferu klávesnice (segment 0040h) 


              0040h:0017h  - přesmykače  bit 0: 1=pravý Shift stisknut 
                                         bit 1: 1=levý Shift stisknut
                                         bit 2: 1=některý Ctrl stisknut
                                         bit 3: 1=některý Alt stisknut
                                         bit 4: 1=Scroll Lock zapnut
                                         bit 5: 1=Num Lock zapnut
                                         bit 6: 1=Caps Lock zapnut
                                         bit 7: 1=Insert zapnut 
              0040h:0018h  - rozšířený statut přesmykačů
                                         bit 0: 1=levý Ctrl stisknut 
                                         bit 1: 1=levý Alt stisknut
                                         bit 2: 1=klávesa SysRq stisknuta
                                         bit 3: 1=probíhá obsluha Pause
                                         bit 4: 1=klávesa Scroll Lock stisknuta
                                         bit 5: 1=klávesa Num Lock stisknuta
                                         bit 6: 1=klávesa Caps Lock stisknuta
                                         bit 7: 1=klávesa Insert stisknuta
                             Pozn.: Opakovaným  nulováním  bitu 7 lze dosáhnout
                                    autorepeat u Insert.
              0040h:0096h  - bit 4: 1=je rozšířená klávesnice AT 101/102 kláves
              0040h:0097h  - bit 0: 1=svítí Scroll Lock 
                             bit 1: 1=svítí Num Lock 
                             bit 2: 1=svítí Caps Lock
                             bit 6: 1=indikátory LED vyslány na klávesnici 
              Ke změně stavu LED postačí změnit stav přesmykačů 0040h:0017h.
INT 0Ah  - přerušení při zpětném běhu EGA, kaskádní přerušení AT (IRQ 2)
INT 0Bh  - přerušení od sériového portu COM 2 a COM 4 (IRQ 3) 
           Adresa portů je uložena na 0040h:0002h (COM 2) a 0040h:0006h (COM 4)
INT 0Ch  - přerušení od sériového portu COM 1 a COM 3 (IRQ 4)
           Adresa portů je uložena na 0040h:0000h (COM 1) a 0040h:0004h (COM 3)
INT 0Dh  - přerušení od řadiče pevného disku XT a od tiskárny LPT2/LPT4 (IRQ 5)
           Adresa portů je uložena na 0040h:000Ah (LPT 2) a 0040h:000Eh (LPT 4)
           Též přerušení AT při chybě paměti - slovní operace na offetu 0FFFFh 
INT 0Eh  - přerušení od řadiče pružných disků (IRQ 6)
INT 0Fh  - přerušení od tiskárny LPT1/LPT3 (IRQ 7), přeruš. AT při matem. chybě
           Adresa portů je uložena na 0040h:0008h (LPT 1) a 0040h:000Ch (LPT 3)














INT 10h  - obsluha displeje, v AH je požadovaná funkce 

              AH = 0  nastavení videomódu AL 
                       U EGA a VGA se nastavením bitu 7 displej nemaže.

|13 |grafika|320x200| 16 barev|adresa A000h|8 stránek  |(EGA, VGA)          |
|14 |grafika|640x200| 16 barev|adresa A000h|4 stránky  |(EGA, VGA)          |
|15 |grafika|640x350|monochrom|adresa A000h|2 stránky  |(EGA, VGA)          |
|16 |grafika|640x350| 16 barev|adresa A000h|2 stránky  |(EGA, VGA)          |

+---+-------+-------+---------+------------+-----------+--------------------+ 
              AH=1   nastavení velikosti kurzoru (pouze textové módy) 
                     CH=začátek, CL=konec (módy 0 až 3 = 0-7, mód 7 = 0-13)
              AH=2   nastavení pozice kurzoru (BH=stránka, DH=řádek, DL=pozice)
              AH=3   navrácení pozice a velikosti kurzoru (vstup BH=stránka,
                     výstup -> DH=řádek, DL=pozice, CH=začátek, CL=konec kurz.)
              AH=4   čtení pozice světelného pera (nemá již VGA)
              AH=5   nastavení aktivní stránky displeje na AL 
              AH=6   rolování okna o AL řádků nahoru (BH=barva nových řádků, 
                     CH=horní  řádek, CL=levá pozice, DH=spodní řádek, DL=pravá
                     pozice); používá se též k vymazání okna (AL=0)
              AH=7   rolování okna o AL řádků dolů (jako předešlá služba)
              AH=8   čtení  znaku  a  atributu  z  pozice kurzoru (též grafické
                     módy) (vstup BH=stránka, výstup AL=znak, AH=atribut)
              AH=9   zápis   znaku  a  atributu  na  pozici  kurzoru  (AL=znak,
                     BH=stránka, BL=atribut barvy, CX=počet zápisů)
              AH=0Ah zápis znaku na pozici kurzoru, barva zůstává původní
              AH=0Bh nastavení palet barev (módy CGA);
                      BH=0: BL=pozadí 0-31 (graf. mód) nebo okolí (text. mód)
                      BH=1: (módy 4 a 5) BL=0 palety bez modré, BL=1 s modrou
              AH=0Ch zápis grafického bodu (AL=barva, CX=X, DX=Y, BH=stránka)
              AH=0Dh čtení grafického bodu (CX=X, DX=Y, BH=stránka -> AL=barva)
              AH=0Eh zápis   znaku   v  telegrafním  módu  (AL=znak,  BL=barva,
                     BH=stránka);  v  textovém  módu  zůstává  barva obrazovky;
                     interpretují  se řídicí znaky 08h (BS), 0Dh (CR), 0Ah (LF)
                     a 09h (TAB), přesahem konce obrazovky řádky rolují
              AH=0Fh navrácení videomódu (->AL mód, AH=pozic/řádek, BH=stránka)
              AH=10H nastavení palet EGA, VGA 
                      AL=0   nastavení registru BL (0-15) na paletu BH (0-63)
                      AL=1   nastavení registru okolí na paletu BH (0-63) 
                      AL=2   nastavení registrů a okolí na palety ES:DX (17 B)
                      AL=3   nastavení blikání (BL=1) / jasného pozadí (BL=0)
                      AL=10h nastavení   registru  BX  (0  až  255)  karty  VGA

    Služby modulu operačního systému DOS se vyvolávají instrukcí INT 21H, v
registru AH je přitom uloženo číslo požadované funkce. V dalších registrech
jsou  uloženy  parametry podle požadavků funkce. Ovlivnění dalších registrů
je  závislé  na prováděné operaci; obsah registru AL je zničen téměř každou
funkcí.

Pozn.: Z  důvodů  slučitelnosti  se  staršími verzemi DOSu jsou možné ještě
       další dvě možnosti volání služeb DOSu:

         1.- Umístit  číslo  funkce  do  AH  a  provést  vzdálené volání na
             relativní  adresu  0050H  v prefixu programového segmentu PSP.
             Tuto metodu nelze použít pro verze DOS nižší než 2.0.

         2.- Do  registru  CL  umístit  číslo  funkce  a  ostatní  registry
             nastavit  podle  funkčních  specifikací. Pak se provede volání
             uvnitř  programového  segmentu  na  paměťové místo 0005H. Toto
             paměťové  místo  obsahuje  vzdálené  volání dispečera funkce v
             DOS.  Při použití této metody se vždy zruší obsah registru AX.
             Tato  metoda  je použitelná jen pro volání funkcí 00H až 24H a
             používala  se u starších programů typu COM. Pro nově vytvořené
             programy je nevhodná.

    Pokud  je  u  dané  služby uveden příklad (ukázkový program), lze tento
příklad  použít  v makroassembleru MASM s tím, že ukázková část programu se
včlení  do jednotné struktury programu (tato struktura slouží jako příklad,
je  zároveň uložena jako zdrojový soubor pro nové programy vúC:\ASSEMB\ pod
názvem SOURCE.ASM):

(Pozn.: Příklady  jsou  zjednodušeny  vypouštěním  instrukcí  nastavujících
        registry  před  každou  funkcí, neboť zůstávají nastaveny předešlou
        funkcí.  Při  běžném  psaní  programu je však vhodné tyto instrukce
        psát  důsledně,  neboť  se  tím sníží chybovost při zápisu programu
        nebo při jeho pozdější modifikaci.)


===========================================================================

COMMENT %
               poznámka - obsahuje popis programu
        %

;--------------------------------------------------------------------------
;                            Segment zásobníku
;--------------------------------------------------------------------------

stack    SEGMENT   stack

         DW        256 DUP(?)               ; zásobník

stack    ENDS

;--------------------------------------------------------------------------
;                            Programový segment
;--------------------------------------------------------------------------

code     SEGMENT   page
         ASSUME    cs:code,ds:code,ss:stack

start:                                      ; hlavní tělo programu
         mov       ax,SEG code              ; segment dat=segment programu
         mov       ds,ax                    ; nastavení datového segmentu

         ; ..............................................
         ;  PROGRAM - zde je umístěn program z příkladu
         ; ..............................................

         mov       ah,4ch                   ; ukončení programu
         int       21h

code     ENDS

         END       start               ; startovací adresa programu

===========================================================================



    K překladu programu lze použít následující příkazový soubor:


IF NOT EXIST C:\ASSMEB\SOURCE\%1.ASM COPY C:\ASSEMB\SOURCE.ASM
                                                    C:\ASSMEB\SOURCE\%1.ASM
:START
C:\ASSEMB\EDITOR C:\ASSEMB\SOURCE\%1.ASM
C:\ASSEMB\MASM C:\ASSEMB\SOURCE\%1 /Z;
IF ERRORLEVEL == 1 GOTO START
C:\ASSEMB\LINK %1,C:\ASSEMB\EXEC\%1;
IF ERRORLEVEL == 1 GOTO START
DEL %1.OBJ


    Makroassembler  (MASM.EXE),  spojovací  program  (LINK.EXE) a příkazový
soubor  (ASM.BAT)  jsou umístěny na disku C: v adresáři C:\ASSEMB. Zdrojový
text  programu  (text  v běžném ASCII formátu a s rozšířením jména .ASM) je
uložen  v adresáři C:\ASSEMB\SOURCE, přeložený program je uložen v adresáři
C:\ASSEMB\EXEC.    Překlad    se    spustí   zapsáním   příkazového   řádku
C:\ASSEMB>ASMújméno_programu  (bez udání rozšíření souboru). Program EDITOR
je  editor  sloužící k editaci textu programu. Pokud je vyvolán nový (ještě
neexistující)  soubor  .ASM, použije se zdrojový text (uvedený výše), který
je uložen v adresáři C:\ASSEMB\ pod jménem SOURCE.ASM.

 F u n k c e   0 0 H  ( 0 )  - přerušení programu

    vstup:    AH = 00H
              CS = adresa segmentu prefixu programového segmentu PSP

    výstup:   žádný

    Funkce ukončuje program a navrací řízení do DOS.

    DOS  přeruší program, vyprázdní buffery souborů, navrátí obsahy vektorů
INT  22H,  INT  23H  a  INT  24H  z prefixu programového segmentu PSP - tj.
výstupní  adresy  (vektory)  pro  ukončení (adr. 0AH), <Ctrl>-<Break> (adr.
0EH)  a kritické chyby (adr. 12H) a předá řízení na adresu vektoru ukončení
programu v PSP (návrat do otcovského procesu).

    Před  vyvoláním  služby  nejdříve  uzavřete  všechny  soubory. Potom se
přesvědčte, zda CS obsahuje adresu segmentu PSP.

Pozn.: Tato  funkce  je  volána  pomocí přerušení INT 20H a pracuje stejným
       způsobem.  Služba  je  historickým pozůstatkem nemající žádné výhody
       oproti   funkci  4CH  (ukončení  programu)  a  zůstává  pouze  kvůli
       slučitelnosti  se  staršími programy. Proto používejte raději funkci
       4CH, která umožňuje navrátit chybový kód použitelný jiným programem.




 F u n k c e   0 1 H  ( 1 )  - vstup znaku z klávesnice s echem

    vstup:    AH = 01H

    výstup:   AL = přečtený znak ze standardního vstupu

    Funkce čte znak ze standardního vstupního zařízení (obvykle klávesnice)
a  provede  též  jeho echo (tj. kopírování znaku i na výstup) na standardní
výstupní zařízení (obvykle obrazovka). Funkce čeká na příchod znaku

    Pokud je stisknuta klávesa se speciální funkcí (např. kurzorové klávesy
a  pod.),  navrátí funkce v AL nejdříve kód 00H; opětným voláním funkce lze
přečíst orientační kód klávesy (viz tabulka kódů kláves).

    Při  duplikování  znaku na displej se provádějí řídící kódy BEL (07H) =
pípnutí, BS (08H) = krok kurzoru zpět a vymazání posledního znaku, HT (09H)
=  tabelátor,  LF  (0AH) = přesun na následující řádek, FF (0CH) = vymazání
obrazovky, CR (0DH) = přechod na začátek řádku a při nainstalovaném driveru
obrazovky ANSI.SYS též ESC (1BH) = speciální řídící funkce.

    Kombinace  kláves  <Ctrl>-<Break>  nebo  <Ctrl>-C  vygeneruje přerušení
INTú23H (uživatelské přerušení).

 F u n k c e   0 3 H  ( 3 )  - vstup znaku z přídavného zařízení

    vstup:    AH = 03H

    výstup:   AL = přečtený znak z přídavného zařízení

    Funkce  čte  znak  (čeká  na  jeho  příchod) ze standardního přídavného
zařízení  AUX.  Standardním  přídavným zařízením (označení AUX) je normálně
první  sériový  port  COM1.  Vstup  nepoužívá vyrovnávací paměť, není řízen
přerušením  a  probíhá  formou  čekání  na  příchod  znaku.  Při zpracování
přicházejících   znaků   je   proto   nutné,  aby  aplikační  program  mezi
jednotlivými  vstupy  neprováděl  prodlevy,  neboť by mohlo dojít ke ztrátě
dat.  Měl by si zajistit vhodnou formou komunikačního protokolu, aby mu byl
vysílán  pouze  určitý počet bajtů, které si nejdříve ukládá do vyrovnávací
paměti  a  až  přijde  přesně  definovaný  počet  bajtů, provede zpracování
přijatých  dat  a vyzve protější zařízení k vyslání dalšího balíku dat.

2400  baud,  8údatových  bitů,  jeden  stop bit, žádná parita. Povelem MODE
(externí příkaz operačního systému) lze tyto hodnoty měnit.

Pozn.: Pokud  je  detekována  kombinace  kláves  <Ctrl>-<Break> (<Ctrl>-C),
       potom je vygenerováno přerušení INT 23H.

       Vstup  znaku  není  ukládán  do bufferu a není řízen přes přerušení;
       pokud váš program není schopen číst znaky plnou rychlostí, mohou být
       data ztracena.

       Funkce  neumožňuje  monitorování  stavu  komunikačního portu (zda je
       připraven  přijatý  znak).  Pro  větší  kontrolu nad portem použijte
       přerušení  INT 14H ROM-BIOSu. Viz též popis adaptéru sériových portů
       a přerušení INT 0CH a INT 0BH.

 F u n k c e   0 6 H  ( 6 )  - přímý vstup/výstup znaku na konzolu

    vstup:    AH = 06H
              DL = FFH            - vstup znaku z klávesnice (nečeká)
                   jiná hodnota   - znak k výstupu na displej

    výstup:   AL = znak z klávesnice (pokud je vstup z klávesnice DL=FFH)
              ZF = (ovlivněn, pokud je vstup z klávesnice - tj. DL=FFH)
                   0 (NZ) - přijat znak z klávesnice (AL = znak)
                   1 (ZR) - není připraven znak z kávesnice (AL = 0)

    Pokud  je  v  registru  DL  uložena  hodnota  FFH, je prováděn vstup ze
standardního  vstupního  zařízení  (obvykle  klávesnice), nečeká na příchod
znaku.  Funkce  testuje, zda je připraven znak ze vstupního zařízení. Pokud
ano,  je  znak  uložen do registru AL a je vynulován příznak nuly ZF. Pokud
není  připraven znak, je příznak ZF nastaven a obsah registru AL je nulový.
Při vstupu znaku není prováděno echo na výstupní zařízení (displej).

    Pokud  je v registru DL uložena jiná hodnota než FFH, je obsah registru
považován  za  znak,  který  má  být vyslán na standardní výstupní zařízení
(displej).

    Pokud  je  při vstupu znaku navrácena v registru AL nula (a pokud je to
platný  znak,  tj.  příznak ZF je vynulován - tj. platí podmínka NZ), jde o
zvláštní  řídící  znak  (např.  funkční  nebo  kurzorová  klávesa).  Druhým
vyvoláním   této  funkce  je  navrácena  druhá  část  speciálního  znaku  -
orientační kód klávesy (viz tabulku kódů kláves).

    Funkce neprovádí detekci kombinace kláves <Ctrl>-<Break> (<Ctrl>-C).

    Při  výstupu  znaku  se  provádějí  řídící kódy BEL (07H) = pípnutí, BS
(08H)  =  krok  kurzoru  zpět  a  vymazání  posledního  znaku,  HT  (09H) =
tabelátor,  LF  (0AH)  =  přesun  na následující řádek, FF (0CH) = vymazání
obrazovky, CR (0DH) = přechod na začátek řádku a při nainstalovaném driveru
obrazovky ANSI.SYS též ESC (1BH) = speciální řídící funkce.

Příklad: Následující příklad vypisuje na obrazovce kódy kláves v HEX tvaru.
         Pokud  je  stisknuta  speciální klávesa (generuje první bajt = 0),
         zobrazí  se  nejdříve  znak  "*" a potom její orientační kód v HEX
         tvaru. Ukončení programu je možné pomocí klávesy <Esc>.

         cyklus:  mov       ah,6            ; funkce vstupu znaku z konzoly
                  mov       dl,0ffh
                  int       21h             ; vstup znaku z konzoly
                  jz        cyklus          ; nebyl zadán žádný znak (čeká)
                  test      al,al           ; test - je AL = 0 ?
                  jnz       cykl2           ; AL není = 0
                  mov       dl,'*'          ; označení rozšířeného kódu
                  jmp       short cykl3     ; tisk prefixu "*"
         cykl2:   cmp       al,27           ; je znak <Esc> ?
                  jz        konec           ; konec programu
                  call      bajt            ; tisk bajtu v AL v HEX tvaru
                  mov       dl,13           ; znak CR
                  int       21h             ; tisk znaku CR
                  mov       dl,10           ; znak LF
         cykl3:   int       21h             ; tisk znaku LF
                  jmp       short cyklus
                                            ; podprogram tisku bajtu HEX
         bajt:    push      ax              ; znak k výstupu
                  ror       al,1            ; rotace AL o 4 bity vpravo
                  ror       al,1
                  ror       al,1
                  ror       al,1
                  call      hex             ; tisk znaku HEX
                  pop       ax              ; návrat znaku k tisku
         hex:     and       al,0fh          ; nižší tetráda znaku
                  add       al,90h          ; převod na znak HEX
                  daa
                  adc       al,40h
                  daa
                  mov       ah,6            ; funkce pro výstup znaku
                  mov       dl,al           ; znak k výstupu na konzolu
                  int       21h             ; výstup znaku na konzolu
                  ret
         konec:                             ; konec programu

 F u n k c e   0 9 H  ( 9 )  - tisk řetězce

              DS:DX = ukazatel na textový řetězec ukončený znakem $

    výstup:   žádný

 F u n k c e   0 A H  ( 1 0 ) - vstup textu ze vstupního zařízení

    vstup:    AH = 0AH
              DS:DX = ukazatel  na  vstupní  vyrovnávací paměť

    výstup:   žádný (návrat informací ve vstupním bufferu)
              (navráceno AL = ukončovací znak 0DH)

    Funkce  čte  řetězec  znaků  ze  standardního  vstupního zařízení až po
zadání  klávesy  <Enter>  (znak  s kódem 0DH = 13) nebo po zaplnění vstupní
vorovnávací  paměti  (tj.  je zadán počet znaků MAX-1, kde MAX je maximální
počet  znaků  nastavený  v  prvním  bajtu vyrovnávací paměti). Při zadávání
znaků  ze  vstupního  zařízení  (klávesnice) provádí echo znaků na výstupní
zařízení  (displej).  Znaky  (včetně ukončovacího znaku <Enter> = 0DH) jsou
ukládány do bufferu DS:DX počínaje offsetem 02H (třetí bajt).

    Struktura vstupního bufferu textu:

         offset 00H (1.bajt): (hodnota  1  až 254) maximální počet znaků ve
                              vyrovnávací  paměti  včetně  znaku CR (0DH) -
                              tuto  hodnotu  musí  uživatel  nastavit  před
                              vyvoláním funkce.
         offset 01H (2.bajt): skutečný  počet zadaných znaků textu bez CR -
                              tato hodnota je nastavena funkcí
         offset 02H (3.bajt): vyrovnávací   paměť;  musí  být  alespoň  tak
                              dlouhá, jak udává 1.bajt.

    Maximální  počet  zadaných znaků je omezen velikostí vstupního bufferu,
která  je  udána  prvním  bajtem vstupního bufferu DS:DX (max. 255 zadaných
znaků včetně CR). Tuto hodnotu nastavuje uživatel před vyvoláním funkce.

    Při návratu je v bufferu DS:DX na offsetu 1 (tj. druhý bajt vyrovnávací
paměti)  navrácen  počet  platných znaků, které byly zaznamenány do bufferu
(bez koncového znaku CR - 0DH). Text je vždy ukončen znakem CR

    Funkce   provádí   kontrolu   zadání  kombinace  kláves  <Ctrl>-<Break>
(<Ctrl>-C), při detekci této kombinace provede přerušení INT 23H.

Pozn.: Bějem  zadávání  textu  pomocí  této  funkce  jsou aktivní editovací
       povely  DOS.  Znaky  obsažené  v  bufferu  (včetně bajtu délky) před
       voláním   funkce  jsou  použity  jako  dočasné  a  povely  DOS  mají
       následující  účinek: Klávesa <Esc> zobrazí znak \ a obnovuje editaci
       (navrátí  ji  do původního stavu), <F3> zobrazí celý dočasně uložený
       text  až  po  konec, <F5> zobrazí znak @ a uloží současný řádek jako
       dočasný  (tj.  lze  jej editovat), klávesy <-- a --> ruší a obnovují
       znak z dočasného textu atd.

       Pokud  se  buffer  naplní  do kapacity bez jednoho bajtu, DOS odmítá
       všechny  zadávané  znaky  kromě  ukončovací  klávesy  <Enter> (resp.
       některých povelů editoru), ozývá se zvukový signál chyby.

 F u n k c e   0 C H  ( 1 2 ) - vymazání vstup. bufferu a provedení funkce

    vstup:    AH = 0CH
              AL = funkce, která se má provést (01H, 06H, 07H, 08H, 0AH)
                   jakákoliv jiná hodnota - neprovádí se další zpracování

    výstup:   AL = zadaný znak (pokud vztažná funkce nebyla 0AH)
                 = 0, pokud nebyla v AL žádná funkce klávesnice

    Funkce  vymaže všechny znaky ze vstupní vyrovnávací paměti znaků, potom
provede specifikovanou funkci vstupu (číslo funkce v registru AL). Použijte
tuto  funkci  pokud  si  chcete  být  jisti,  že program přijme nový znak z
klávesnice aniž by použil znaky zadané během dřívějších operací. Obvykle se
tato  funkce  používá  např. při ohlášení chybového stavu a čekání na další
volby uživatele.

Pozn.: Při  zadání  funkce  06H  nemusí provádět funkce pouze vstup znaku z
       klávesnice,  ale  může  provést  i výstup znaku na výstupní zařízení
       (viz detaily funkce 06H).

       Pokud  chcete  vynulovat  vstupní  buffer  bez  provedení  jakékoliv
       operace (bez čtení znaku), zadejte funkci AL = 06H a DL = 0FFH (test
       připravenosti znaku z klávesnice).




 F u n k c e   0 D H  ( 1 3 ) - reset disku

    vstup:    AH = 0DH

    výstup:   žádný

    Funkce  vyprázdní  všechny  vyrovnávací  paměti  souborů,  soubory však
neuzavírá.  Zapisuje  modifikované  vyrovnávací  paměti  na  disk  a označí
všechny  vnitřní  vyrovnávací  paměti  jako volné. K zajištění uložení změn
položky  souboru  v adresáři použijte před vyvoláním této funkce některou z
funkcí  pro  uzavření souboru (10H nebo 3EH). Funkce se nemusí vyvolat před
výměnou  disku,  jestliže  všechny  soubory,  v  nichž došlo ke změně, byly
uzavřeny. Obvykle se tato funkce používá k zajištění známého stavu systému.
Tuto funkci by měly volat programy obsluhující <Ctrl>-<Break>.




 F u n k c e   0 E H  ( 1 4 ) - výběr aktivního disku

    vstup:    AH = 0EH
              DL = číslo aktivního disku (0 = A, 1 = B atd.)

    výstup:   AL = počet logických disků v systému

    Funkce nastaví aktivní disk a navrátí počet disků v systému libovolného
typu, včetně pevných disků a logických disků.

Pozn.: Disketová  jednotka  v  jednodisketovém  systému  se počítá jako dva
       logické disky A: a B:.

       DOS  verze  3.x  a  pozdější  verze  hlásí  5 logických disků, pokud
       neobsahuje CONFIG.SYS jiné přiřazení pomocí LASTDRIVE.

       K  určení  počtu  fyzických  disketových jednotek v systému použijte
       přerušení  INT  11H  (17).  K  určení  počtu pevných disků v systému
       použijte přerušení INT 13H (19)/funkci 08H.

       Použijte  funkci  DOS  19H  (poskytnutí  aktivního  disku), pokud se
       chcete přesvědčit o správnosti operace.




 F u n k c e   0 F H  ( 1 5 ) - otevření souboru s použitím FCB

    vstup:    AH = 0FH
              DS:DX = ukazatel na neotevřený FCB souboru

    výstup:   AL = 00H - soubor úspěšně otevřen (a FCB správně vyplněn)
                   FFH - soubor nenalezen nebo jej nelze otevřít

    Funkce  otevře existující soubor s použitím FCB souboru. DS:DX obsahuje
adresu  neotevřeného  řídícího  bloku  FCB.  Jmenovaný  soubor  se  hledá v
aktivním  adresáři aktivního disku nebo disku specifikovaného v položce FCB
(tj.  první  bajt  FCB:  0=aktivní  disk; 1=A; 2=B; ...). Nalezne-li se pro
soubor  vyhovující adresářová položka, AL vrátí hodnotu 0, soubor se otevře
v  kompatibilním přístupovém módu (viz funkce DOS 3DH - otevření souboru) a
FCB se vyplní následovně:

    - Je-li  kód  diskové  jednotky 0 (implicitní disk), změní se příslušná
      položka FCB na aktivní použitý disk (1=A, 2=B, atd.).

    - Položka aktivní blok se vynuluje.

    - Délka záznamu se nastaví na sytémovou implicitní hodnotu 128 (80H).

    - Délka  souboru,  datum  a čas posledního zápisu do souboru se nastaví
      podle adresářové položky.

    Před  provedením sekvenční diskové operace se souborem se musí nastavit
položka  aktivní záznam. Před provedením diskové operace s přímým přístupem
se  souborem  se  musí  nastavit  položka  relativní  záznam. Nevyhovuje-li
implicitní  délka  záznamu  128  bajtů, je nutno ji nastavit na požadovanou
délku před provedením následující diskové operace.




 F u n k c e   1 0 H  ( 1 6 ) - uzavření souboru s použitím FCB

    vstup:    AH = 10H
              DS:DX = ukazatel na otevřený FCB souboru

    výstup:   AL = 00H - soubor úspěšně uzavřen
                   FFH - soubor nenalezen


    Funkce  uzavře  soubor  a  uloží jeho adresářovou položku do adresáře s
použitím FCB. Tato funkce se musí vyvolat po provedených změnách v souboru,
aby se aktualizovala adresářová položka.

    Položka  adresáře  musí být na svém původním místě v současném aktivním
adresáři a disku, z kterého byl soubor otevřen.

    Je-li  pro  soubor  nalezena  odpovídající adresářová položka, umístění
souboru  se  porovná  s  odpovídajícími položkami v FCB. Pokud je to nutné,
aktualizuje  se adresářová položka podle FCB a vyrovnávací paměť souboru se
vyprázdní. AL vrátí hodnotu 0.

Pozn.: Pokud  uzavíráte soubor na disketě, DOS se snaží nejdříve určit, zda
       byla  v disketové jednotce vyměněna disketa. Pokud ano, navrací v AL
       hodnotu  0FFH.  Určování  výměny disket není spolehlivé v dřívějších
       verzích  DOS  než  3.0;  použití  této  funkce  v DOS 2.x při výměně
       diskety může mít za následek zničení obsahu diskety.



 F u n k c e   1 1 H  ( 1 7 ) - nalezení prvního souboru s použitím FCB

    vstup:    AH = 11H
              DS:DX = ukazatel na neotevřený FCB souboru

    výstup:   AL = 00H - soubor nalezen (a DTA vyplněna)
                   FFH - žádný soubor nenalezen

    Funkce  hledá  v  aktivním  adresáři  první vyhovující soubor. DS:DX je
adresa  neotevřeného FCB, který může obsahovat konvenční znaky (tj. * a ?).
K  prohledávání skrytých nebo systémových souborů musí DX ukazovat na první
bajt rozšířeného FCB.
•
Pozn.: Předpokládané  použití  této služby je ovládání souborů obsahujících
       maskovací znaky "?" ve svém jméně (univerzální znak - na této pozici
       může být uveden jakýkoliv znak). Tato funkce zahájí porces hledání a
       funkce  12H  (18)  pokračuje  v  hledání  následujících vyhovujících
       souborů.

       Funkci  29H  (rozložené  jméno  souboru)  lze  použít  pro vytváření
       neotevřeného FCB souboru v přípravě pro hledání.

       Pokud  je  soubor nalezen, vytvoří se na současné adrese pro diskové
       přenosy   (DTA)   neotevřený   FCB   stejného  typu  (normální  nebo
       rozšířený).  Před  voláním této funkce je potřeba se přesvědčit, zda
       je dostatek místa rezervovaného na DTA pro CFB; pokud není, je nutno
       nastavit pomocí funkce 1AH novou adresu DTA.

       Pokud funkce hledání používá rozšířený FCB (FCBE), je FCBE uložen na
       adrese  DTA s nastaveným bitem identifikátoru (offset -7) na hodnotu
       0FFH.

       Rozsah  hledání můžete řídit zadáním bajtu atributů v rozšířeném FCB
       (offset  -1).  Pokud  je bajt atributů nastaven na 00H, hledá funkce
       pouze  normální soubory (tj. mohou mít nastaven pouze atribut "pouze
       čtení"  a/nebo  "archivní"). Pokud je v bajtu atributu specifikována
       nějaká  kombinace  atributů "skrytý soubor", "systémový soubor" nebo
       "adresář",  budou  se  vyhledávat  normální  soubory  a také všechny
       soubory  s  těmito  atributy. Pokud je v bajtu atributů specifikován
       atribut   "návěští  disku",  bude  funkce  hledat  pouze  položku  s
       atributem  "návěští  disku".  Atributy  "pouze  čtení"  a "archivní"
       nemají vliv na hledání.

         Struktura bajtu atributů souboru:
        +-+-+-+-+-+-+-+-+
        |7 6 5 4 3 2 1 0|
        +++++++++++++++++ bit
         | | | | | | | +-> 0 (  1): pouze čtení souboru (Read-only "R/O")
         | | | | | | +---> 1 (  2): skrytý soubor (Hidden "HID")
         | | | | | +-----> 2 (  4): systémový soubor (System "SYS")
         | | | | +-------> 3 (  8): návěští disku (Volume Label "VOL")
         | | | +---------> 4 ( 16): adresář (Directory "DIR")
         | | +-----------> 5 ( 32): archivní soubor (Archive "ARC")
         | +-------------> 6 ( 64): rezervováno (musí být nastaven na 0)
         +---------------> 7 (128): rezervováno (musí být nastaven na 0)

            - bližší popis atributů viz "Adresářová položka"

       FCB  jsou pozůstatky z DOS 1. Je výhodnější použít k hledání souborů
       funkce 4EH a 4FH.




 F u n k c e   1 2 H  ( 1 8 ) - nalezení dalšího souboru s použitím FCB

    vstup:    AH = 12H
              DS:DX = ukazatel  na  neotevřený FCB souboru specifikovaný ve
                      funkci 11H nebo 12H

    výstup:   AL = 00H - další soubor nalezen
                   FFH - soubor nenalezen

    Funkce  hledá  v  aktivním  adresáři  další  vyhovující  soubor.  DS:DX
obsahuje adresu FCB specifikovaného v předchozím hledání pomocí funkce 11H.
Funkce  12H  se  používá  po  funkci  11H  (vyhledání  prvního vyhovujícího
souboru) k nalezení dalších vyhovujících adresářových položek.

Varování: Informace  potřebné  funkcí  12H  jsou  zničeny  jakoukoliv jinou
          operací  používající  vytváření  FCB  souboru  (jako např. funkce
          11H).  Proto,  pokud chcete hledat více souborů a provádět v nich
          též  vstupně/výstupní  operace, musíte uložit informace k hledání
          tak, že uložíte FCB.


Příklad: Následující  příklad  provádí  výpis souborů aktivního adresáře na
         aktivním  disku (podobně jako příkaz DIR) na obrazovku a to v pěti
         sloupcích.

              mov       ah,1ah              ; funkce nastavení DTA
              mov       dx,offset buffer    ; adresa bufferu jako DTA
              int       21h                 ; nastavení adresy DTA
              mov       ah,11h              ; funkce nalezení první položky
              mov       dx,offset fcb       ; adresa FCB
              int       21h                 ; nalezení první položky FCB
              inc       al                  ; je AL=FFH ? (tj. nenalezen)
              mov       dx,offset neni      ; textchybového hlášení
              jz        konec1              ; není soubor v adresáři
    vypis:    mov       si,offset buffer+1  ; adresa FCB nalezeného souboru
              mov       cx,8                ; počet znaků jména
              mov       ah,2                ; funkce výstupu znaku
    jmeno:    mov       dl,[si]             ; znak jména souboru k tisku
              int       21h                 ; tisk znaku na displej
              inc       si                  ; další znak jména souboru
              loop      jmeno               ; další znak jména
              mov       dl,"."              ; oddělovací znak tečky
              int       21h                 ; tisk oddělovací tečku
              mov       cx,3                ; počet znaků rozšíření souboru
    typ:      mov       dl,[si]             ; znak typu souboru k tisku
              int       21h                 ; tisk znaku typu souboru
              inc       si                  ; další znak typu souboru
              loop      typ                 ; tisk dalšího znaku typu
              mov       dl," "              ; oddělovací mezera
              int       21h                 ; tisk 4 oddělovacích mezer
              int       21h
              int       21h
              int       21h
              mov       ah,12h              ; funkce vyhledání dalšího s.
              mov       dx,offset fcb       ; adresa FCB
              int       21h                 ; nalezení dalšího souboru
              inc       al                  ; je AL=FFH ? (tj. nenalezen)
              jnz       vypis               ; je další soubor
              mov       dx,offset tiskcr    ; odřádkování textu
    konec1:   mov       ah,9                ; funkce tisku textu
              int       21h                 ; tisk textu
              jmp       konec               ; konec programu

    neni      db        'V adresáři není žádný soubor.'
    tiskcr    db        13,10,'$'
    fcb       db        0,"???????????"
              db        25 dup (0)
    buffer    db        128 dup (0)

    konec:                                      ; konec programu




 F u n k c e   1 3 H  ( 1 9 ) - zrušení souboru s použitím FCB

    vstup:    AH = 13H
              DS:DX = ukazatel na neotevřený FCB souboru

    výstup:   AL = 00H - soubor nalezen a zrušen
                   FFH - soubor nenalezen

    Funkce  zruší  všechny  soubory  s  aktivním  adresáři,  které  splňují
podmínky dané FCB souboru.

   Při práci v síti vyžaduje tato funkce přístupová práva vytváření CREATE.

Pozn.: Specifikace  souboru  může obsahovat znaky "?" nahrazující jakýkoliv
       znak ve specifikaci jména souboru.

       Soubory read-only nebudou touto funkcí zrušeny.





 F u n k c e   1 4 H  ( 2 0 ) - sekvenční čtení ze souboru s použitím FCB

    vstup:    AH = 14H
              DS:DX = ukazatel na otevřený FCB

    výstup:   AL = 00H - čtení proběhlo úspěšně
                   01H - nalezen konec souboru, žádná data nepřečtena
                   02H - prostor DTA příliš malý (nebo přelom segmentu)
                   03H - nalezen konec souboru, přečtena část dat

    Funkce  čte  sekvenčně  následující záznam souboru do bufferu na adrese
DTA,  po  čtení  inkrementuje  ukazatele v FCB souboru na další záznam (tj.
inkrementuje aktivní blok a aktivní záznam). Před vyvoláním funkce musí být
v FCB nastaveny položky aktivní blok a aktivní záznam.

    Při práci v síti vyžaduje tato funkce přístupová práva čtení READ.

Pozn.: Čísko  sekvenčního  záznamu  je  odvozeno  z  hodnot aktivního bloku
       (offset  0CH)  a  aktivního záznamu (offset 20H) v FCB souboru. Tyto
       položky  FCB  jsou  automaticky  zaznamenány po operaci čtení. Počet
       čtených bajtů je použit z položky velikosti záznamu na offsetu 0EH v
       FCB.

       Data  jsou čtena do bufferu na adrese označené jako Adresa diskového
       přenosu  DTA.  Pokud by přenos dat mohl způsobit přetečení segmentu,
       je vygenerována chyba 2.

       Pokud  je  nalezen konec souboru ještě před načtením celého záznamu,
       je zbytek záznamu doplněn nulami až do plné velikosti záznamu.

Příklad: Následující  program  vypíše  na obrazovku z aktivního adresáře na
         aktivním  disku  textový  soubor  DIRINFO  (pokud existuje), který
         obsahuje  informace o nastaveném adresáři (tento informační soubor
         používá též Norton Commander).

              mov       ah,1AH              ; funkce nastavení DTA
              mov       dx,offset buffer    ; adresa bufferu
              int       21h                 ; nastavení adresy DTA
              mov       ah,0fh              ; funkce otevření souboru
              mov       dx,offset fcb       ; adresa fcb
              int       21h                 ; otevření souboru
              inc       al                  ; je AL = FFH ? (tj. nenalezen)
              jz        konec               ; konec programu
              mov       [fcb+14],1          ; nastavení délky záznamu na 1
    cteni:    mov       dx,offset fcb       ; adresa fcb
              mov       ah,14h              ; funkce sekvenčního čtení
              int       21h                 ; sekvenční čtení záznamu
              or        al,al               ; je správné čtení ?
              jnz       zavri               ; konec - uzavreni souboru
              mov       dl,[buffer]         ; přečtený znak
              cmp       dl,1ah              ; je znak konce souboru ?
              je        zavri               ; konec souboru - uzavři
              mov       ah,2                ; funkce výstupu znaku
              int       21h                 ; zobrazení znaku
              jmp       short cteni         ; další znak ze souboru
    zavri:    mov       ah,10h              ; funkce uzavření souboru
              mov       dx,offset fcb       ; adresa fcb
              int       21h                 ; uzavření souboru
              jmp       short konec         ; konec programu

    fcb       db        0,"DIRINFO    "     ; položka FCB souboru
              db        25 dup (0)
    buffer    db        1 dup (?)           ; zásobník 1 znaku

    konec:                                  ; konec programu





 F u n k c e   1 5 H  ( 2 1 ) - sekvenční zápis do souboru s použitím FCB

    vstup:    AH = 15H
              DS:DX = ukazatel na otevřený FCB

    výstup:   AL = 00H - zápis proběhl úspěšně
                   01H - disk je plný
                   02H - prostor DTA příliš malý (nebo přelom segmentu)

    Funkce zapisuje sekvenčně data z bufferu na adrese DTA do následujícího
záznamu  souboru,  po  zápisu inkrementuje ukazatele v FCB souboru na další
záznam (tj. inkrementuje aktivní blok a aktivní záznam).

    Při práci v síti vyžaduje tato funkce přístupová práva zápisu WRITE.

Pozn.: Čísko  sekvenčního  záznamu  je  odvozeno  z  hodnot aktivního bloku
       (offset  0CH)  a  aktivního záznamu (offset 20H) v FCB souboru. Tyto
       položky  FCB  jsou  automaticky zaznamenány po operaci zápisu. Počet
       zapisovaných  bajtů je použit z položky velikosti záznamu na offsetu
       0EH v FCB.

       Data  jsou  zapisována  na  disk  z  bufferu na adrese označené jako
       Adresa  diskového  přenosu  DTA.  Pokud  by přenos dat mohl způsobit
       přetečení segmentu, je vygenerována chyba 2.

       Pokud zapisovaná data nevyplní zapisovaný sektor, DOS ukládá data do
       bufferu pro evenuální zápis pokud jsou data v bufferu nashromážděna.

       Pokud  má specifikovaný soubor nastaven atribut ochrany proti zápisu
       Read-Only, zápis se neprovede.

Příklad: Program  zde  uvedený  odstraňuje tabelátory z textového souboru a
         nahrazuje  je  odpovídajícím  počtem  mezer.  Převáděný  soubor se
         zadává  při  vyvolání  programu  jako  parametr za jménem programu
         (používá  se  položka  FCB  na adrese 005CH v prefixu programového
         segmentu).  Soubor  musí  být v aktivním adresáři (v aktivním nebo
         uvedeném  disku).  Jako  výstupní  soubor  se  (pro  jednoduchost)
         vytvoří  soubor  stejně  pojmenovaný  jako  zdrojový soubor, ale s
         označením typu $$$.

                                            ; program používá FCB souboru
                                            ; na adrese ES:005CH
         mov       ax,es                    ; datový segment
         mov       ds,ax                    ; datový segment
         mov       ax,cs                    ; segment programu
         mov       es,ax                    ; segment programu
         mov       si,5ch                   ; zdrojová adresa
         mov       di,offset fcb            ; cílová adresa
         mov       cx,12                    ; počet znaků jména
         rep       movsb                    ; přenos jména souboru
         mov       si,5ch                   ; zdrojová adresa FCB
         mov       di,offset fcbout         ; výstupní soubor
         mov       cx,9                     ; délka - jen jméno
         rep       movsb                    ; přenos jména souboru
         mov       ax,cs                    ; segment programu
         mov       ds,ax                    ; segment programu
         mov       dx,offset buffer         ; buffer znaku souboru
         mov       ah,1ah                   ; funkce nastavení adresy DTA
         int       21h                      ; nastavení adresy DTA
         mov       dx,offset fcb            ; adresa FCB souboru k převodu
         mov       ah,0fh                   ; funkce pro otevření souboru
         int       21h                      ; otevření souboru
         inc       al                       ; byl soubor nalezen ?
         jz        hlaseni                  ; chybové hlášení
         mov       word ptr [fcb+14],1      ; délka záznamu = 1 znak
         mov       ah,16h                   ; funkce vytvoření souboru
         mov       dx,offset fcbout         ; výstupní soubor
         int       21h                      ; vytvoření souboru
         inc       al                       ; je volné místo ?
         jz        hlaseni                  ; není místo v adresáři
         mov       word ptr [fcbout+14],1   ; délka záznamu = 1 znak
prevod:  mov       ah,14h                   ; funkce sekvenčního čtení
         mov       dx,offset fcb            ; adresa fcb souboru
         int       21h                      ; čtení znaku ze souboru
         or        al,al                    ; je chyba ?
         jnz       zavri                    ; konec - uzavři soubor
         mov       al,[buffer]              ; znak ze souboru
         mov       cx,1                     ; počet znaků k zápisu
         cmp       al,0ah                   ; znak LF ?
         je        zapis                    ; zápis znaku LF
         cmp       al,0dh                   ; je znak CR ?
         jne       nenicr                   ; není znak CR
         mov       word ptr [pozice],0      ; vynulování pozice
         jmp       short zapis              ; zápis znaku
nenicr:  inc       word ptr [pozice]        ; zvýšení pozice
         cmp       al,9                     ; znak tabelátoru ?
         jne       zapis                    ; není - zápis znaku
         dec       word ptr [pozice]        ; návrat pozice
         mov       ax,[pozice]              ; pozice znaku
         and       ax,0fff8h                ; nastavení na předchozí tabel.
         add       ax,8                     ; nastavení na další tabelátor
         mov       bx,ax                    ; úschova nové pozice
         sub       ax,[pozice]              ; počet znaků k tabelaci
         mov       [pozice],bx              ; nová pozice
         mov       cx,ax                    ; počet vložených mezer
         mov       al,' '                   ; oddělovací znak mezery
zapis:   mov       [buffer],al              ; znak k zápisu do souboru
         mov       dx,offset fcbout         ; výstupní soubor
         mov       ah,15h                   ; funkce zápisu znaku
znak:    int       21h                      ; zápis znaku
         or        al,al                    ; je chyba ?
         jnz       hlaseni                  ; chyba - hlášení chyby
         loop      znak                     ; zápis dalšího znaku
         jmp       short prevod             ; další znak k převodu
zavri:   mov       ah,10h                   ; funkce uzavření souboru
         mov       dx,offset fcb            ; adresa fcb
         int       21h                      ; uzavření souboru
         mov       dx,offset fcbout         ; záložní fcb
         int       21h
         jmp       short konec
hlaseni: mov       dx,offset chyba
         mov       ah,9
         int       21h
         jmp       short konec

chyba    db        'Chyba !',13,10,'$'      ; chybové hlášení
pozice   dw        0                        ; čítač pozice na řádku
buffer   db        1                        ; buffer znaku
fcbout   db        0,'        $$$'          ; výstupní soubor
         db        25 dup (?)
fcb      db        0,'           '          ; převáděný soubor
         db        25 dup (?)
konec:                                      ; konec programu

 F u n k c e   1 A H  ( 2 6 ) - nastavení adresy diskového přenosu (DTA)

    výstup:   žádný

    Adresa   diskového  přenosu  DTA  (Disk  Transfer  Address)  je  adresa
vyrovnávací  paměti,  do  které  jsou  ukládána  (nebo z ní čtena) data při
diskovém  přenosu  ze  souboru  (do  souboru).  Diskové  přenosy se nemohou

nedostačující velikosti prostoru DTA.

       o  délce  128  bajtů  na offsetu 80H v prefixu programového segmentu
       (PSP).

       Rezervujte  dostatečný prostor bufferu; pokud DOS zjistí, že by data
       při přenosu přetekla přes okraj segmentu, abortuje diskový přenos.

       Tato  funkce  se  používá  s operacemi čtení a zápisu pomocí FCB a s
       operacemi  pro  nalezení prvního a následujícího souboru používající
       FCB.

       by  přenos  dat  mohl  způsobit  přetečení segmentu, je vygenerována
       chyba 2.

       Pokud  je  nalezen konec souboru ještě před načtením celého záznamu,
       je zbytek záznamu doplněn nulami až do plné velikosti záznamu.

       Po  načtení  požadovaného  záznamu  uloží  tato funkce novou hodnotu
       položky  relativního záznamu a položky aktivní blok a aktivní záznam
       tak,  že  ukazují  na  nový záznam. Funkce 21H je jednodušší obměnou
       této funkce, kromě toho, že funkce 21H neukládá automaticky posledně
       jmenované  tři  položky  a  může  číst  pouze  jeden záznam na jedno
       volání.





 F u n k c e   2 8 H   ( 4 0 ) - zápis bloku s přímým přístupem s použ. FCB

    vstup:    AH = 28H
              CX = počet záznamů k zápisu
              DS:DX = ukazatel na otevřený FCB

    výstup:   AL = 00H - zápis proběhl úspěšně
                   01H - disk je plný
                   02H - prostor DTA příliš malý (přelom segmentu)
              CX = počet zapsaných záznamů

    Funkce  zapisuje  jeden  nebo více záznamů ze současné adresy diskových
přenosů  DTA na disk. Počet záznamů specifikuje registr CX. Zápis začíná na
relativní  adrese  záznamu  (offset 21H). Velikost záznamů je specifikována
položkou  velikosti  záznamu  (offset  0EH). Položky aktivní blok a aktivní
záznam se nastaví odpovídajícím způsobem k položce relativní záznam.

    Při práci v síti vyžaduje tato funkce přístupová práva zápisu WRITE.

Pozn.: Použijte  funkci 1AH k nastavení adresy diskových přenosů DTA. Pokud
       by  přenos  dat  mohl  způsobit  přetečení segmentu, je vygenerována
       chyba 2.

       Pokud  zapisovaný záznam nezaplní celý sektor (512 Bajtů), DOS uloží
       data do vyrovnávací paměti a uloží sektor až po jeho naplnění (resp.
       až ve chvíli, kdy je požadován přístup na jiný sektor než který je v
       paměti).

       Pokud  specifikovaný soubor má nastaven atribut "pouze čtení", zápis
       se neprovede.

       Pokud  specifikujete  hodnotu  v  CX  =  0  (počet  záznamů), funkce
       nezapíše   žádný  záznam,  avšak  zkrátí  délku  souboru  na  pozici
       specifikovanou  číslem  relativního záznamu. Tato funkce se používá,
       pokud  chcete logicky zrušit záznamy za koncem souboru a uvolnit tak
       místo na disku.

       Po  zápisu  požadovaného  záznamu  uloží  tato  funkce novou hodnotu
       položky  relativního záznamu a položky aktivní blok a aktivní záznam
       tak,  že  ukazují  na  nový záznam. Funkce 22H je jednodušší obměnou
       této funkce, kromě toho, že funkce 22H neukládá automaticky posledně
       jmenované  tři  položky a může zapisovat pouze jeden záznam na jedno
       volání.




 F u n k c e   2 9 H   ( 4 1 ) - rozbor jména souboru

    vstup:    AH = 29H
              DS:SI = ukazatel na řetězec, který má být rozebrán
              ES:DI = ukazatel na neotevřenou položku FCB
              AL = parametry rozboru:
                   bit 0 - zkoumání od posledního odděl. znaku (ingorován)
                       1 - identifikační  bajt  disku  v FCB je modifikován
                           pouze  pokud  je  disk specifikován v příkazovém
                           řádku
                       2 - jméno  souboru v FCB je modifikováno pouze pokud
                           je  jméno  souboru  specifikováno  v  příkazovém
                           řádku
                       3 - rozšíření  jména  souboru  v FCB je modifikováno
                           pouze   pokud   je   rozšíření   jména   souboru
                           specifikováno v příkazovém řádku
                       4-7 ignorovány

    výstup:   AL = FFH - funkce neproběhla úspěšně
                   00H - funkce úspěšná, nenalezeny žádné maskovací znaky
                   01H - funkce úspěšná, nalezeny maskovací znaky (?,*)
              DS:SI = první bajt po řetězci, který se rozebíral
              ES:DI = nový neotevřený FCB

    Funkce  29H  provádí  rozbor  příkazového řádku pro specifikaci souboru
pomocí  formy d:JMÉNO_SOUBORU.TYP. Pokud je nalezeno jméno souboru, vytvoří
se  FCB.  Jinak  funkce  navrací v AL hodnotu FFH. Funkce umožňuje programu
nastavit  aktivní  disk,  jméno  souboru  a rozšíření (typ) jména souboru a
ponechat na uživateli, aby změnil tyto aktivní hodnoty.

Pozn.: DS:SI ukazuje na lokaci řetězce specifikace souboru, jehož rozbor má
       být  proveden  (text  z příkazového řádku). ES:DI ukazuje na lokaci,
       kde  bude  vytvořen  nový FCB. V nižší tetrádě registru AL (tj. jeho
       nižší čtyři bity) jsou specifikovány parametry pro rozbor:

         - bit 0: Pokud  je  nastaven  na  1, hledá se jméno souboru i přes
                  počáteční  oddělovací znaky souborů (např. mezera). Pokud
                  je  nastaven  na  0, předpokládá se, že jméno specifikace
                  souboru začíná na prvním bajtu příkazového řádku.

         - bit 1: Pokud je nastaven na 1, nastaví funkce bajt disku pouze v
                  případě, že povelový řádek obsahuje specifikaci disku. To
                  umožňuje programu definovat svůj vlastní implicitní disk.
                  Pokud je nastaven na 0, je disk nastavem na specifikovaný
                  disk nebo na implicitní disk (hodnota 0).

         - bit 2: Pokud  je nastaven na 1, změní funkce jméno souboru v FCB
                  pouze  v  případě,  že  nalezne  platné  jméno  souboru v
                  příkazovém  řádku.  To  umožňuje  programu  nastavit  své
                  implicitní    jméno    souboru,   které   může   uživatel
                  předefinovat. Pokud je bit nastaven na 0 a není v řetězci
                  specifikováno  jméno souboru, nastaví se jméno souboru na
                  8 mezer.

         - bit 3: Pokud  je  nastaven  na  1,  změní funkce rozšíření jména
                  souboru   v  FCB  pouze  v  případě,  že  nalezne  platné
                  rozšíření  jména souboru v příkazovém řádku. Pokud je bit
                  nastaven  na  0  a  není  v  řetězci  specifikováno jméno
                  souboru, nastaví se jméno souboru na 3 mezery.


       Pokud  funkce  nalezne  ve  specifikaci jména souboru maskovací znak
       "*",  nahradí  zbytek  jména  souboru  nebo  rozšíření jména souboru
       maskovacími znaky "?". Pokud je zbytek rozboru úspěšný, navrátí v AL
       hodnotu   01H   informující   program,   že   musí   použít   funkce
       nalezni_první/nalezni_další (tj. funkce 11H a 12H).

       Pokud  operace  neproběhne  úspěšně,  navrátí AL hodnotu FFH a druhý
       bajt FCB (ES:DI+1) bude prázdný.

       Funkce  29H  nemůže  pracovat  s  popisem cest souborů. Soubory jsou
       popsány  pouze  ve  tvaru d:jméno.typ (d=označení disku; jméno=jméno
       souboru; typ=typ souboru, rozšíření jména souboru).

       Jako oddělovače jména souboru se používají znaky:
         : . ; , = + / " [ ] < > | mezera tabelátor

       Ukončovací  znaky  jména  souboru  zahrnují všechny oddělovací znaky
       plus  jakýkoliv  řídící  znak  (tj. znak s kódem menším než 20H=32).
       Jméno souboru nemůže obsahovat ukončovací znak jména souboru.

 F u n k c e   2 E H   ( 4 6 ) - zapnutí nebo vypnutí přepínače VERIFY

    vstup:    AH = 2EH
              AL = 00H - vypnutí přepínače VERIFY
                   01H - zapnutí přepínače VERIFY
              DL = 00H

    výstup:   žádný

    Funkce  2EH  umožňuje  zapnout  nebo  vypnout přepínač VERIFY. Pokud je
přepínač  VERIFY  zapnut  (AL  = 01H), čte DOS bajty kontrolního součtu CRC
(Cyclic  Redundancy  Check) právě zapisovaných dat a ověřuje, zda jsou data
správně  zapsána.  Nastavení  tohoto  přepínače  tedy  nezpůsobí  ověřování
správnosti  zápisu  dat  kontrolním  čtením  dat  po zápisu (a porovnáním s
původními  daty),  provádí  pouze  kontrolu  čitelnosti  dat pomocí ověření
kontrolního  součtu. Tento přepínač je vhodné zapnout při zápisu kritických
dat  na  disk,  v  běžném provozu je vhodnější jej vypnout, neboť zpomaluje
provádění diskových operací.

Pozn.: U verzí DOS 1 a 2 musí být DL nastaven před voláním funkce na 0.

       Síťové disky nepodporují funkci pro verifikaci dat.

       K  zjištění  stavu  přepínače VERIFY použijte funkci 54H (poskytnutí
       nastavení přepínače VERIFY).

 F u n k c e   3 9 H   ( 5 7 ) - vytvoření adresáře (MKDIR)

    vstup:    AH = 39H
              DS:DX = ukazatel na jméno adresáře k vytvoření (řet. ASCIIZ)

    výstup:   AX = chybový kód (pokud je CF = 1) - viz funkce DOS 59H
                   03H - cesta nenalezena
                   05H - požadavek odmítnut nebo adresář již existuje

    Funkce  39H  (MKDIR)  vytváří  podadresář, jehož cesta je specifikována
pomocí  řetězce  ASCIIZ  na  adrese  DS:DX.  Délka řetězce je omezena na 64
znaků.  Pokud funkce není schopna vytvořit adresář, nastaví příznak přenosu
CF a navrátí chybový kód v registru AX.

   Při práci v síti vyžaduje tato funkce přístupová práva vytváření CREATE.

Pozn.: Jméno adresáře může obsahovat označení disku.

       Pokud některý z adresářů v cestě neexistuje, adresář se nevytvoří.

       Použijte  funkci 59H k získání rozšířeného chybového kódu (DOS 3.0 a
       vyšší).




 F u n k c e   3 A H   ( 5 8 ) - zrušení adresáře (RMDIR)

    vstup:    AH = 3AH
              DS:DX = ukazatel na jméno adresáře k zrušení (řetězec ASCIIZ)

    výstup:   AX = chybový kód (pokud je CF = 1) - viz funkce DOS 59H
                   03H ( 3) - cesta nenalezena
                   05H ( 5) - požadavek odmítnut (adresář není prázdný)
                   10H (16) - nelze zrušit aktivní adresář

    Funkce 3AH (RMDIR) ruší podadresář, jehož cesta je specifikována pomocí
řetězce ASCIIZ na adrese DS:DX. Délka řetězce je omezena na 64 znaků. Pokud
funkce  není  schopna  zrušit adresář, nastaví příznak přenosu CF a navrátí
chybový kód v registru AX.

   Při práci v síti vyžaduje tato funkce přístupová práva vytváření CREATE.

Pozn.: Použijte  funkci 59H k získání rozšířeného chybového kódu (DOS 3.0 a
       vyšší).





 F u n k c e   3 B H   ( 5 9 ) - změna adresáře (CHDIR)

    vstup:    AH = 3BH
              DS:DX = ukazatel na jméno nového adresáře (řetězec ASCIIZ)

    výstup:   AX = chybový kód (pokud je CF = 1) - viz funkce DOS 59H
                   03H ( 3) - cesta nenalezena

    Funkce  3BH  (CHDIR) změní aktivní adresář na nový adresář, jehož cesta
je  specifikována  pomocí  řetězce ASCIIZ na adrese DS:DX. Délka řetězce je
omezena na 64 znaků. Pokud funkce není schopna nalézt nový adresář, nastaví
příznak  přenosu  CF a navrátí chybový kód v registru AX (a adresář zůstane
nezměněn).

Pozn.: Použijte  funkci 59H k získání rozšířeného chybového kódu (DOS 3.0 a
       vyšší).

       Označení  nové  cesty  může obsahovat označení disku (změní se cesta
       pro daný disk).





 F u n k c e   3 C H   ( 6 0 ) - vytvoření souboru (CREAT)

    vstup:    AH = 3CH
              CX = atributy souboru
              DS:DX = ukazatel na jméno nového souboru (řetězec ASCIIZ)

    výstup:   AX = identifikátor souboru (pokud není CF nastaven)
                 = chybový kód (pokud je CF = 1) - viz funkce DOS 59H
                   03H ( 3) - cesta nenalezena
                   04H ( 4) - není  volný  žádný identifikátor souboru (tj.
                              je otevřeno příliš mnoho souborů)
                   05H ( 5) - požadavek  odmítnut  (soubor má ochranu proti
                              zápisu nebo je základní adresář plný)

    Funkce  3CH  otevře soubor, jehož jméno je specifikováno pomocí řetězce
ASCIIZ  na  adrese DS:DX. Pokud soubor ještě neexistuje, vytvoří jej. Pokud
soubor  se specifikovaným jménem již existuje, zkrátí jej na nulovou délku,
tj.  zruší všechna stará data ze souboru (!). Soubor je otevřen pro čtení i
zápis.

   Při práci v síti vyžaduje tato funkce přístupová práva vytváření CREATE.

Pozn.: Použijte  funkci 59H k získání rozšířeného chybového kódu (DOS 3.0 a
       vyšší).

       Označení  nové  cesty  může obsahovat označení disku (změní se cesta
       pro daný disk).

       Registr CX specifikuje atributy vytvářeného souboru:
         +----------+-------------------------------+
         |    CX    | specifikované atributy        |
         +----------+-------------------------------+
         |  00H (0) | normální soubor               |
         |  01H (1) | soubor pouze pro čtení (R/O)  |
         |  02H (2) | skrytý soubor (HID)           |
         |  04H (4) | systémový soubor              |
         +----------+-------------------------------+
         - součtem hodnot můžete atributy kombinovat (blíže viz "Adresářová
           položka")

       Informace může být zapisována i do souboru vytvořeného v módu "pouze
       čtení".  Ovšem  při  použití  této  funkce  k  otevření existujícího
       souboru s nastaveným příznakem "pouze čtení" bude generována chyba.

       Ke změně atributů souboru lze použít funkci CHMOD (43H).




 F u n k c e   3 D H   ( 6 1 ) - otevření souboru

    vstup:    AH = 3DH
              AL = mód otevření
              DS:DX = ukazatel na jméno souboru (řetězec ASCIIZ)

    výstup:   AX = identifikátor souboru (pokud není CF nastaven)
                 = chybový kód (pokud je CF = 1) - viz funkce DOS 59H
                   01H ( 1) - neplatné číslo funkce
                   02H ( 2) - soubor nenalezen
                   03H ( 3) - cesta nenalezena
                   04H ( 4) - není   volný   žádný   identifikátor  souboru
                              (příliš mnoho otevřených souborů)
                   05H ( 5) - požadavek  odmítnut
                   0CH (12) - mód otevření neplatný

    Funkce  3DH  otevře  soubor  (a  přiřadí mu identifikační slovo), jehož
jméno  je  specifikováno  pomocí  řetězce ASCIIZ na adrese DS:DX s použitím
bajtu  "mód  otevření"  k  určení,  jakým  způsobem bude prováděn k souboru
přístup.  Funkce otevře jakýkoliv existující soubor včetně skrytých souborů
a nastaví velikost záznamu na 1úbajt.

    Tyto  bity  řídí způsob, jakým mohou ostatní uživatelé v síti otevřít a

Příznak podílu (bit 7 registru AL) - pouze DOS 3.0 a vyšší:

    Příznak  podílu  (bit  7)  specifikuje,  zda se budou podílet podřazené
procesy  na  používání  tohoto  souboru.  Pokud  je  bit  7 vynulován, mají
podřazené  procesy  automaticky  přístup  k  tomuto souboru. Pokud je bit 7
nastaven,  soubor  se  automaticky neovolňuje pro podřízený proces. Avšak ,
jako  jakýkoliv  jiný  proces,  může  požadovat přístup k souboru podřízený
proces na bázi sdílení.

 +---+------------------------------------------+
 | 7 |              příznak podílu              |
 +---+------------------------------------------+
 | 0 |  na souboru se podílí podřízený proces   |
 | 1 |  podřízený proces se na souboru nepodílí |
 +---+------------------------------------------+

Zpřístupnění otevřeného souboru podřazeným procesům:

    Je-li  soubor  jednou  otevřen hlavním procesem, je zpřístupnění tohoto
souboru  jiným  procesům  určeno  módem sdílením i módem přístupu původního
procesu,  stejně  tak  jako  módem  sdílením  a  módem přístupu podřazeného
procesu.

    1.- Soubor  je  poprvé  otevřen  v kompatibilním módu sdílení, pokud je
        otevřen:

         - přes funkce používající FCB
         - přes funkce vyžadující práva vytváření CREATE
         - přes volanou funkci, ve které je kompatibilní mód specifikován

        Soubor  v  kompatibilním  módu  může  být  otevřen  jedním procesem
        libovolněkrát,  pokud  soubor  není  dosud  otevřen  pod některým z
        ostatních čtyř módů sdílení. Avšak pokud má soubor nastaven atribut
        "pouze  čtení"  a  je  v  současnosti  otevřen  v  módu  sdílení se
        zamítnutím  zápisu,  může  být tento soubor otevřen v kompatibilním

 F u n k c e   4 2 H   ( 6 6 ) - přemístění ukazatele souboru (LSEEK)

    vstup:    AH = 42H
              BX = identifikátor souboru
              CX:DX = nový offset v bajtech (32-bitové celé číslo se znam.)
              AL = kód módu
                   00H (0) - přesunutí  ukazatele  souboru  CX:DX  bajtů od
                             začátku souboru
                   01H (1) - přesunutí  ukazatele  souboru o CX:DX bajtů od
                             současné pozice
                   02H (2) - přesunutí  ukazatele  souboru o CX:DX bajtů od
                             konce souboru

    výstup:   DX:AX = nová pozice ukazatele souboru (32-bit.číslo se znam.)
              nebo AX = chybový kód (pokud je CF = 1) - viz funkce DOS 59H
                   01H (1) - neplatný kód módu
                   06H (6) - neplatný identifikátor souboru

    Funkce  změní  logickou  pozici  ukazatele  pro operace čtení/zápis pro
specifikovaný  soubor  zvýšením  nebo  snížením  hodnoty ukazatele souboru.
Offset,  který se přičítá k ukazateli souboru se předává v registrovém páru
CX:DX  jako  32-bitové celé číslo se znaménkem; významnější část offsetu je
uložena  v  registru  CX.  Kód  módu,  specifikovaný v AL, indikuje, zda se
offset  uložený v CX:DX vztahuje k začátku souboru (mód 0), současné pozici
ukazatele souboru (mód 1) nebo ke konci souboru (mód 2).

Pozn.: Použijte  funkci 59H k získání rozšířeného chybového kódu (DOS 3.0 a
       vyšší).

       Nezávisle  na tom, který mód je v AL specifikován, pozitivní hodnota
       offsetu  v  CX:DX  způsobí  vždy zvýšení hodnoty ukazatele souboru a
       negativní  způsobí snížení hodnoty. Proto v módu 2 pozitivní hodnota
       offsetu CX:DX způsobí přesunutí ukazatele souboru za konec souboru.

       Chcete-li  přesunout  ukazatel  na  konec souboru nebo zjistit délku
       souboru, použijte kód módu 2 a offset CX:DX = 0

       Ukazatel  souboru  je možné přesunout na pozici ležící před začátkem
       souboru  nebo  za  koncem  souboru. Přesunutí ukazatele před začátek
       souboru  sice  nezpůsobí  hlášení  chyby,  avšak  bude chybná příští
       operace čtení nebo zápisu.

       Soubor  může  být  rozšířen  přesunutím  ukazatele  souboru za konec
       souboru a zápisem jednoho nebo více bajtů dat na tuto novou pozici.

       Soubor může být zkrácen přesunutím ukazatele souboru na novou pozici
       požadovaného  konce souboru a provedením operace zápisu (funkce 40H)
       s nastaveným nulovým počtem bajtů k zápisu (CX = 0).





 F u n k c e   4 3 H   ( 6 7 ) - poskytnutí/nastavení atrib. soub. (CHMOD)

              AL = 00H (0) - poskytnutí atributů souboru

           +-----------+---------------------------------+
           |    CX     |   specifikovaný atribut         |

           |    01H    |   pouze čtení souboru (R/O)     |
           |    02H    |   skrytý soubor (HID)           |

       ostatní bity bajtu atributů adresáře. Stačí, když pomocí této funkce

|          | adresu DS:DX (znakové zařízení)                              |
| 03H ( 3) | zápis bajtů z paměti na adrese DS:DX do řídícího             |
|          | kanálu zařízení (znakové zařízení)                           |
| 04H ( 4) | čtení bajtů z řídícího kanálu zařízení do paměti na          |
|          | adresu DS:DX (blokové zařízení)                              |
| 05H ( 5) | zápis bajtů z paměti na adrese DS:DX do řídícího             |
|          | kanálu zařízení (blokové zařízení)                           |
| 06H ( 6) | poskytnutí vstupního statutu zařízení                        |
| 07H ( 7) | poskytnutí výstupního statutu zařízení                       |

 F u n k c e   4 4 0 0 H   ( 6 8 - 0 ) - IOCTL: poskytnutí inf. o zařízení

   |   7  |   nastaven pro indikaci, že se jedná o zařízení              |
   | 8-13 |   rezervováno                                                |

   +------+--------------------------------------------------------------+

   | 8-13 |   rezervováno                                                |
   |  14  |   nastaven, pokud je možno zařízení ovládat řídícím řetězcem |
   |      |   přes funkce 4404H a 4405H                                  |
   |  15  |   rezervováno                                                |
   +------+--------------------------------------------------------------+

 F u n k c e   4 4 0 E H   ( 6 8 - 1 4 ) - IOCTL:poskytnutí logického disku

       disková   operace.   Hlášení   můžete  odstranit  nastavením  nového

 F u n k c e   4 5 H   ( 6 9 ) - zdvojení identifikátoru souboru (DUP)

       původní   identifikátor  přitom  zůstává  i  nadále  otevřen,  takže
       nemusíte soubor znovu otevírat, což je časově náročná operace.

 F u n k c e   4 7 H   ( 7 1 ) - poskytnutí aktivního adresáře

 F u n k c e   4 8 H   ( 7 2 ) - přidělení paměti

    vstup:    AH = 48H
              BX = počet odstavců paměti, která má být přidělena

    výstup:   AX = adresa segmentu přidělené paměti (pokud CF = 0)
                 = chybový kód (pokud je CF = 1) - viz funkce DOS 59H
                   07H (7) - řídící blok paměti zničen
                   08H (8) - nepostačující paměť

úspěšná,  ukazuje AX:0000H na začátek přiděleného bloku paměti (AX obsahuje
adresu segmentu; offset je vždy 0000H).



Pozn.: Použijte  funkci 59H k získání rozšířeného chybového kódu (DOS 3.0 a
       vyšší).

       Pokud  nastavíte  před  voláním  funkce BX=FFFFH, můžete tuto funkci
       použít  k  zjištění,  jak velká část paměti je volná (je navrácena v
       registru  BX).  To vyvolá chybu, kterou však můžete ignorovat, neboť
       DOS nemůže přidělit paměť větší než 640K.

 F u n k c e   4 B H   ( 7 5 ) - načtení nebo provedení programu (EXEC)

    vstup:    AH = 4BH
              AL = 00H - načtení programu a jeho start
                   03H - načtení programu, avšak nebude odstartován
              DS:DX = ukazatel  na  řetězec  ASCIIZ  specifikující označení
                      cesty k podprogramu
              ES:BX = ukazatel na blok parametrů

    výstup:   AX = chybový kód (pokud je CF = 1) - viz funkce DOS 59H
                   01H ( 1) - neplatné číslo funkce
                   02H ( 2) - soubor nenalezen
                   03H ( 3) - cesta nenalezena
                   05H ( 5) - požadavek odmítnut
                   08H ( 8) - nepostačující paměť
                   0AH (10) - neplatné prostředí
                   0BH (11) - neplatný formát

    Funkce mění všechny registry.

    Funkce  4BH  umožňuje  programu  zavést  podprogram z disku do paměti a
(pokud je to požadováno) spustit jej. Při zavedení programu se z otcovského
procesu  zduplikují  do  synovského  procesu  všechny  otevřené  soubory  a
prostředí  procesu - to umožňuje, aby otcovský proces přesměroval podle své
potřeby  např.  vstupní  a  výstupní zařízení a potom vyvolal mapř. třídící
program.

    Pokud  je  v  AL  zadána  hodnota  00H,  podprogram se načte do paměti,
vytvoří  se  jeho prefix programového segmentu PSP a program se odstartuje.
Vektory ukončení a obsluhy Ctrl-Break se nastaví na adresu instrukce, která
následuje za voláním této funkce EXEC v hlavním programu, takže po ukončení
podprogramu  z  disku  se řízení navrátí do hlavního programu, jakoby šlo o
volání běžného podprogramu.

    Pokud  je  v  AL  zadána  hodnota  03H,  podprogram se načte z disku do
paměti,  nevytvoří  se  však  prefix  programového  segmentu  PSP,  ani  se
podprogram  automaticky  nespustí, avšak hlavní program může do podprogramu
vskočit přímo.

    Do registrového páru DS:DX uložte ukazatel na řetězec ASCIIZ obsahující
označení  disku,  cesty  a  jméno souboru, který se má zavést do paměti. Do
registrů  ES:BX uložte ukazatel na blok parametrů, které specifikují bližší
podmínky pro provedení podprogramu. Blok parametrů má tuto strukturu:

    Pro podfunkci 00H (načti a spusti):
+----------+------------------+-----------------------------------------+
|  offset  | velikost (bajtů) |                 popis                   |
+----------+------------------+-----------------------------------------+
| 00H ( 0) |        2         | adresa segmentu řetězců prostředí       |
| 02H ( 2) |        4         | segment a offset příkazového řádku      |
| 06H ( 6) |        4         | segment a offset prvního aktivního FCB  |
| 0AH (10) |        4         | segment a offset druhého aktivního FCB  |
+----------+------------------+-----------------------------------------+

    Pro podfunkci 03H (načti ale nespouštěj):
+----------+------------------+-----------------------------------------+
|  offset  | velikost (bajtů) |                 popis                   |
+----------+------------------+-----------------------------------------+
| 00H ( 0) |        2         | adresa segmentu kam bude soubor načten  |
| 02H ( 2) |        2         | relokační faktor programu (aplikuje se  |
|          |                  |     pouze pro formáty programů EXE)     |
+----------+------------------+-----------------------------------------+

Prostředí: Řetězce  prostředí,  které  musí  být  seřazeny  po  odstavcích,
           obsahují  posloupnosti  řetězců ASCIIZ následované bajtem 00H po
           všech   řetězcích.   Každý   řetězec  ASCIIZ  má  typicky  formu
           parametr=hodnota. Celkový řetězec prostředí musí být svou délkou
           menší  než  32K. Pokud je segment pro řetězec prostředí nastaven
           na   00H,  sdílí  podprogram  prostředí  programu,  který  tento
           podprogram vyvolal.

           Podprogram  vždy  přijímá  kopii  řetězce prostředí, takže žádná
           změna  provedená v prostředí podprogramu se neodrazí v prostředí
           hlavního programu.

Soubory:   Pokud  je  podprogram  načten  do  paměti  a  vykonáván, všechny
           otevřené  identifikátory  souborů  se  uvolní pro podprogram. To
           znamená, že volající program může přesměrovat standardní vstup a
           výstup  pro  podprogram. Nejsou uvolněny pro podprogram pouze ty
           identifikátory  souborů,  které byly otevřeny s nastaveným bitem
           příznaku podílu (bit 7 registru AL - viz funkce 3DH).

Paměť:     Před  použitím  funkce  4BH  musíte  uvolnit dostatek paměti pro
           načtení podprogramu resp. pro jeho provoz (voz funkce 4AH).

Varování:  Tato  funkce  mění  všechny  registry včetně registru zásobníku.
           Proto  před  voláním  podprogramu  uložte  registry  SS  a SP do
           proměnných  (tj.  na  určitá  paměťová  místa)  uvnitř  hlavního
           programu  a  po návratu z podprogramu nejdříve navraťte tyto dva
           registry a potom teprve můžete opět používat zásobník.

Pozn.:     Funkce EXEC volá zaváděcí část COMMAND.COM k zavedení programu.




 F u n k c e   4 C H   ( 7 6 ) - ukončení procesu (EXIT)

    vstup:    AH = 4CH
              AL = návratový kód

    výstup:   žádný - neexistuje návrat

    Tato  funkce  je  správná  metoda  ukončení  programu v DOS verze 2.0 a
vyšší.  Funkce  uzavře  všechny  soubory  a navrátí řízení zpět do hlavního
(otcovského)  procesu  (obvykle  COMMAND.COM).  Přitom  lze  v  registru AL
specifikovat  návratový  kód,  který  slouží hlavnímu procesu k informaci o
činnosti ukončeného procesu.

Pozn.: Návratový  kód může být testován pomocí funkce 4DH nebo v příkazovém
       souboru systému pomocí příkazu ERRORLEVEL.

       Tato  metoda  ukončení  procesu je výhodnější než přerušení INTú20H,
       neboť CS nemusí obsahovat adresu prefixu záhlaví programu PSP.

Příklad: Následující krátký program je velmi užitečnou maličkostí při práci
         v  operačním  systému. Umožňuje větvit uživatelské volby v systému
         podle zadání z klávesnice. Program čeká na znak z klávesnice (znak
         se nezobrazuje, tato činnost se ponechává na příkazovém souboru) a
         pokud  je  to  písmeno,  navrátí kód odpovídající pořadovému číslu
         písmene (A=0, ..., Z=25) nezávisle na tom, zda jde o velké či malé
         písmeno.  Dále  je uveden krátký příkazový soubor ukazující způsob
         práce s tímto programem (program je zde pojmenován PISMENO.EXE).

         cyklus:   mov       ah,8
                   int       21h            ; čekání na zadání znaku
                   sub       al,"A"         ; odečtení znaku "A"
                   jc        cyklus         ; menší než "A"
                   cmp       al,27
                   jl        konec          ; je platný znak
                   sub       al,32          ; korekce malých písmen
                   jc        cyklus         ; není malé písmeno
                   cmp       al,26          ; je písmeno ?
                   jg        cyklus         ; není malé písmeno
         konec:    mov       ah,4ch
                   int       21h            ; ukončení programu

Příklad povelového souboru:

         echo off
         echo Zadejte vaši volbu (ANO/NE)
         :start
         PISMENO.EXE
         if errorlevel == 14 goto start
         if errorlevel == 13 goto ne
         if errorlevel == 1 goto start
         echo ANO !
         goto start
         :ne
         echo NE !
         goto start

 F u n k c e   5 A H   ( 9 0 ) - vytvoření jedinečného souboru

    vstup:    AH = 5AH
              CX = atributy souboru
              DS:DX = ukazatel na cestu končící znakem \ (řetězec ASCIIZ)

    výstup:   AX = chybový kód (pokud je CF = 1) - viz funkce DOS 59H
                   03H (3) - cesta nenalezena
                   05H (5) - požadavek odmítnut
              DS:DX = ukazatel na jméno souboru (řetězec ASCIIZ)

    Funkce 5AH vytvoří ve specifikovaném adresáři jedinečný soubor a otevře
jej  v  kompatibilním  módu s přístupem "čtení/zápis". Tato funkce se často
používá k vytvoření dočasných souborů, avšak DOS při ukončení programu tyto
soubory automaticky neruší. Tato služba je možná pouze v DOS 3.0 a vyšším.

   Při práci v síti vyžaduje tato funkce přístupová práva vytváření CREATE.

Pozn.: Jméno cesty k adresáři musí končit znakem obráceného lomítka "\".

       Rezervujte  za  řetězcem označení cesty 13 bajtů tak, aby DOS mohl k
       cestě připojit jméno nově vytvořeného souboru.



 F u n k c e   5 B H   ( 9 1 ) - vytvoření nového souboru

    vstup:    AH = 5BH
              CX = atributy souboru
              DS:DX = ukazatel na označení souboru (řetězec ASCIIZ)

    výstup:   AX = identifikátor souboru
                 = chybový kód (pokud je CF = 1) - viz funkce DOS 59H
                   03H (3) - cesta nenalezena
                   04H (4) - není volný žádný identifikátor souboru
                   05H (5) - požadavek odmítnut
                   80H (128) - soubor již existuje

    Tato  funkce  vytvoří  soubor podle specifikovaného označení souboru za
podmínky,  že  tento  soubor dosud neexistuje. Tato funkce je možná pouze v
DOS 3.0 a vyšším.

   Při práci v síti vyžaduje tato funkce přístupová práva vytváření CREATE.

Pozn.: Použijte  funkci 59H k získání rozšířeného chybového kódu (DOS 3.0 a
       vyšší).

       Tato  funkce  je identická funkci 3CH (vytvoření souboru) v případě,
       že  vytvářený  soubor  dosud  ještě  neexistuje.  Pokud  soubor  již
       existuje,  ohlásí  tato  funkce  chybu,  zatímco  funkce 3CH v tomto
       případě  zkrátí  existující  soubor  na  nulovou  délku  a potom jej
       otevře.




 F u n k c e   5 C H   ( 9 2 ) - zamknutí/odemknutí přístupu k souboru

    vstup:    AH = 5CH
              AL = 00H - uzamčení souboru
                   01H - odemknutí souboru
              BX = identifikátor souboru
              CX = relativní adresa začátku oblasti (vyšší slovo)
              DX = relativní adresa začátku oblasti (nižší slovo)
              SI = délka oblasti (vyšší slovo)
              DI = délka oblasti (nižší slovo)

    výstup:   AX = chybový kód (pokud je CF = 1) - viz funkce DOS 59H
                   01H ( 1) - neplatný kód funkce
                   06H ( 6) - neplatný identifikátor souboru
                   21H (33) - porušení   uzamčení   souboru  (specifikovaná
                              oblast je již uzamčena nebo je již odemčena)

    Tato  funkce  se  používá k uzamčení nebo odemčení vybrané části disku,
čímž  zabraňuje  nebo  umožňuje  přístup  k  této oblasti jiným procesům ve
víceúlohovém  režimu  nebo v prostředí sítě. Tato funkce je možná pouze pro
DOS 3.00 a vyšší.

Pozn.: Registry  CX  a DX společně (jako 4-bajtové celé číslo bez znaménka)
       určují  relativní  adresu  (offset;  v  bajtech)  od začátku souboru
       oblasti  uvnitř  souboru,  která  má  být  uzamčena  nebo odemknuta;
       registry  SI  a DI společně (jako 4-bajtové celé číslo bez znaménka)
       specifikují délku této chráněné oblasti.

       Přerušení  procesu,  který má otevřené soubory s uzamčenými oblastmi
       nebo  uzavření  souboru s uzavřenou oblastí bude mít nedefinovatelné
       následky.  Pokud  váš  program  může  být  přerušen pomocí přerušení
       INTú23H  nebo INTú24H, musíte před přerušením programu zajistit, aby
       všechny zámky byly odemčeny.

       Operace  odemknutí  musí  specifikovat přesně stejnou oblast souboru
       jako uzamykací operace.

       Podřízené procesy (tj. proces vytvořený voláním funkce EXEC) nesdílí
       přístup  k  oblastem  souboru,  které  byly  uzamčeny jeho otcovským
       procesem.

       Použijte tuto funkci v následujících módech souboru:
        mód sdílení se zamítnutím čtení
        mód sdílení bez žádného zamítnutí
        mód sdílení se zamítnutím zápisu, soubor je otevřen pro čtení/zápis
        mód sdílení se zamítnutím zápisu, soubor je otevřen pouze pro zápis

 F u n k c e   5 E 0 0 H   ( 9 4 - 0 ) - poskytnutí jména zařízení

    vstup:    AH = 5EH

5F03H).

    Pokud  chcete  získat výpis všech zařízení pro práci v síti, provádějte
tuto  funkci  opakovaně,  počínaje  indexem (BX) nastaveným na 00H, hodnotu
indexu  v  BX  postupně zvětšujte o 1 až bude registr AX hlásit chybový kód
12H (18).



 F u n k c e   5 F 0 3 H   ( 9 5 - 3 ) - přesměrování zařízení

    vstup:    AH = 5FH
              AL = 03H
              BL = typ zařízení (3=tiskárna, 4=disková mechanika)
              CX = uložený parametr (všechny hodnoty kromě 0 jsou rezerv.)
              DS:SI = ukazatel na řetězec ASCIIZ obsahující jméno lokálního
                      zařízení
              ES:DI = ukazatel na řetězec ASCIIZ obsahující cestu pro práci
                      v síti následovanou řetězcem ASCIIZ obsahujícím heslo

    výstup:   AX = chybový kód (pokud je CF = 1) - viz funkce DOS 59H
                   01H (1) - program pro obsluhu práce v síti není načten
                   03H (3) - cesta nenalezena
                   05H (5) - požadavek odmítnut
                   08H (8) - nepostačující paměť

    Funkce  5F03H umožňuje přesměrovat vstup/výstup z lokální tiskárny nebo
diskové  mechaniky  na  síťové  zařízení.  Můžete  také  ovládat  přístup k
síťovému  zařízení  použitím  hesla.  Funkce  je možná pouze pro DOS 3.10 a
vyšší  a  vyžaduje,  aby  běžely  programy  IBM  PC  Network nebo Microsoft
Networks.

Pozn.: Volejte   tuto   funkci  s  nastaveným  kódem  typu  zařízení  v  BL
       (3=tiskárna,  4=disková  mechanika)  a  s  0  v CX. Pár DS:SI by měl
       ukazovat na jméno zařízení, které si přejete přesměrovat a pár ES:DI
       by  měl  ukazovat  na  řetězec  ASCIIZ  udávající  jméno  příjmového
       síťového  zařízení.  Jméno  síťového  zařízení  musí být následováno
       druhým řetězcem ASCIIZ specifikujícím heslo. Heslo může být dlouhé 0
       až  8  znaků; nechcete-li specifikovat žádné heslo, použijte řetězec
       ASCIIZ s nulovou délkou (prvním bajtem je bajt 0).

       Pokud  je  přesměrovávaným zařízením tiskárna, jsou přijatelná jména
       PRN, LPT1, LPT2 a LPT3. Pokud je přesměrovávaným zařízením mechanika
       disku,  měl byt zdrojový řetězec ASCIIZ obsahovat písmeno označující
       disk následované dvojtečkou.

       Zdrojový  řetězec  může být i nulový; v tomto případě se DOS pokouší
       provést přístup na jméno síťového zařízení se specifikovaným heslem.




 F u n k c e   5 F 0 4 H   ( 9 5 - 4 ) - zrušení přesměrování

    vstup:    AH = 5FH
              AL = 04H
              DS:SI = ukazatel  na řetězec ASCIIZ specifikující buď lokální
                      zařízení,  jehož  přesměrování  má  být zrušeno, nebo
                      jemu přiřazené jméno síťového zařízenó.

    výstup:   AX = chybový kód (pokud je CF = 1) - viz funkce DOS 59H

    Tato funkce ruší dříve nastavená přesměrování na síťová zařízení. DS:SI
ukazuje  na  jméno zařízení, jehož přesměrování má být zrušeno, to může být
buď  jméno  tiskárny (PRN, LPT1, LPT2 nebo LPT3), označení disku nebo jméno
síťového zařízení (v posledním případě by měl být řetězec ASCIIZ označující
jméno  síťového  zařízení  následován druhým řetězcem, který obsahuje heslo
spojené  s rušením). Funkce je možná pouze pro DOS 3.10 a vyšší a vyžaduje,
aby běžely programy IBM PC Network nebo Microsoft Networks.

 F u n k c e   6 2 H   ( 9 8 ) - poskytnutí adresy prefixu program.segmentu

    vstup:    AH = 62H

    výstup:   BX = segment prefixu programového segmentu PSP

    Funkce  navrací  v BX adresu segmentu prefixu programového segmentu PSP
současného procesu (tj. program, který právě probíhá). Tato funkce je možná
pouze pro DOS 3.00 a vyšší.


                        +------------------------------+
                        |  Sériový přenos dat, modemy  |
                        +------------------------------+
                                Miroslav Němeček

Sériový  přenos dat je přenos informací pomocí jednoho signálového kanálu. Data
se  přenášejí  postupně po jednotlivých bitech. Pokud jsou okamžiky přechodu od
jednoho  přenášeného  bitu  k  dalšímu  od sebe vždy stejně vzdáleny, pak jde o
přenos   synchronní.   Jsou-li  vzdálenosti  bitů  různé,  jedná  se  o  přenos
asynchronní.  Zvláštním  případem  asynchronního  přenosu  dat  je  přenos  dat
arytmický  - jednotlivé znaky jsou přenášeny asynchronně, avšak jednotlivé bity
uvnitř  znaku jsou přenášeny synchronně. Tato metoda se používá pro asynchronní
přenos dat nejčastěji.

Při  synchronním  přenosu  dat  se  synchronizace  mezi  vysílačem a přijímačem
zabezpečuje  nejčastěji pomocí synchronizačních znaků vysílaných v době, kdy se
nepřenášejí  data.  Pro  udržení  synchronizace  během  vysílání  dat  je nutno
zabezpečit  dostatečný  počet  změn  v datech. Z toho důvodu se používá častěji
zabezpečení  dat pomocí liché parity, která zajistí minimálně jednu změnu během
vysílání jednoho bajtu dat.

U  asynchronního  přenosu  se  k zabezpečení synchronizace vysílá před datovými
bity tzv. START bit (délka 1) a za datovými bity STOP bit (délka 1, 1.5, 2):

       |     "0"  "1"  "1"  "1"  "0"  "0"  "1"  "0"  "1"  "1"
  HIGH | ---+    +--------------+         +----+    +-------------------
       |    |    |    |    |    |         |    |    |    |         |
  LOW  |    +----+    |    |    +---------+    +----+    |         |
      -+----|----|----|----|----|----|----|----|----|----|---------|---
            START  d0   d1   d2   d3   d4   d5   d6 PARITA STOP bit
             bit

Při  příjmu se přijímač synchronizuje na začátek START bitu. Po daných časových
intervalech  se  testují  jednotlivé datové bity. Pokud není po datových bitech
detekován STOP bit, hlásí přijímač chybu rámu (FRAME ERROR).

Při plně duplexním (obousměrném) přenosu dat se mohou data přenášet oběma směry
současně. Při poloduplexním provozu dat se data přenášejí pouze v jednom směru,
využívají  se  stejně  jako  při  duplexním  provozu  dvě  signálové cesty. Při
simplexním  provozu  se  využívá pouze jedna signálová cesta, data se přenášejí
pouze v jednom směru.

-------------------
  1    STB      Strobe - data pro tiskárnu jsou platná (výstup)
2-9    D0-D7    data (výstup)
 10    ACK      Acknowledge - tiskárna převzala data (vstup)
 11    BUSY     Busy - tiskárna není připravena k převzetí dat (vstup)
 12    PE       Paper End - konec papíru (vstup)
 13    SELECT   Select - výběr tiskárny (výstup)
 14    AF       Auto Feed - automatické odstránkování (výstup)
 15    ERROR    Error - chyba tiskárny (vstup)
 16    INIT     Init - inicializace tiskárny (výstup)
 17    SELIN    Select Input - vstup výběru (vstup)
18-25  GND      Ground - zem

BAZE = 378h (LPT1), 278h (LPT2), 3BCh (LPT3)


BAZE+0:  zápis - data pro tiskárnu
         čtení - poslední vyslaný bajt na tiskárnu

BAZE+1:  čtení - bit 0: nepoužit, vždy 0
                 bit 1: nepoužit, vždy 0
                 bit 2: nepoužit, vždy 0
                 bit 3: ERROR (0=chyba tiskárny)
                 bit 4: /SELECT (1=tiskárna aktivována)
                 bit 5: PAPER OUT (1=konec papíru)
                 bit 6: ACK (1=zpracovává znak, 0=připravena pro další znak)
                 bit 7: /BUSY (1=tiskárna připravena, 0=tiskárna nepřipravena)

BAZE+2:  zápis - bit 0: STROBE (1=data na výstupu jsou platná)
                 bit 1: AUTO FEED (1=automatický LF po každém CR)
                 bit 2: /INIT (0=RESET tiskárny)
                 bit 3: SELECT (1=výběr tiskárny)
                 bit 4: IRQ ENABLE (1=povoleno přerušení od tiskárny)
                 bit 5 až bit 7: nevyužito

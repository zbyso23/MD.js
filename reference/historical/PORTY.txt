    * porty 0000H - 00FFH jsou rezerovvány pro použití systémovou deskou

    * porty 0400H a výše nejsou přístupné na systémové sběrnici

    1 . -   N a s t a v e n í   s y s t é m o v ý c h   p ř e p í n a č ů


    Přepínače DIL počítačů PC a XT informují BIOS o vybavení počítače a jak
veliká paměť je nainstalována. Tyto přepínače se čtou během inicializačního
testu  POST  a  nastaví  se  podle  nich příznakové bity v tabulce vybavení
počítače  v  datovém  prostoru  BIOS  (tato  tabulka  na  adrese 0:0410H je
programátorovi přístupná přes přerušení INT 11H).

    Na  původním  PC  (64KB  paměti  na základní desce; někdy se též nazývá
PC-1) byly na systémové desce umístěny dva přepínače DIL, označené jako SW1
a SW2 (pozn.: pokud je přepínač v poloze ON, má signál hodnotu 0):

                              +-----------+-------+-------+-------+-------+
                              | přepínače | 00(0) | 01(1) | 10(2) | 11(3) |
             SW1              +---+---+---+-------+-------+-------+-------+
ON   +1+2+3+4+5+6+7+8+  = 0   | 7 | 5 | 3 |  - -  |  - -  |  - -  |  - -  |
     | | | | | | | | |        +---+---+---+-------+-------+-------+-------+
     | | | | | | | | |  = 1   | 8 | 6 | 4 |  - -  |  - -  |  - -  |  - -  |
OFF  +-+-+-+-+-+-+-+-+        +---+---+---+-------+-------+-------+-------+
      | | | | | | | |   přep.
      | | | | | | +-+--> 7-8: disketových mechanik-1 (00=1;01=2;10=3;11=4)
      | | | | +-+------> 5-6: aktivní mód displeje (rezer.,40zn,80zn,mono)
      | | +-+----------> 3-4: RAM na systémové desce (16K, 32K, 48K, 64K)
      | +-------------->  2:  matematický koprocesor 8087 (OFF=je; ON=není)
      +---------------->  1:  disketové mechaniky (OFF=jsou; ON=žádná)

    Použití  přepínačů  DIL  u  počítače XT je podobné jako u PC s vyjímkou
pozice  1,  která  aktivuje  cyklování inicializačního tesu POST a musí být
proto  vždy  v  poloze  OFF. Odlišné jsou též hodnoty systémové paměti RAM,
které  se  nastavují  pozicemi  3-4  přepínače SW1 - hodnoty paměti jsou (v
odpovídajícím pořadí) 64K, 128K, 192K a 256K.


          SW2 (PC-1)
ON   +1+2+3+4+5+6+7+8+  = 0
     | | | | | | | | |
     | | | | | | | | |  = 1
OFF  +-+-+-+-+-+-+-+-+
      | | | | | | | |   přep.
      | | | | +-+-+-+--> 5-8: vždy v OFF
      +-+-+-+----------> 1-4: celková RAM: pozice 4 = 256K (v OFF platí)
                                           pozice 3 = 128K (v OFF platí)
                                           pozice 2 =  64K (v OFF platí)
                                           pozice 1 =  32K (v OFF platí)
      Celková  kapacita paměti vznikne součtem jednotlivých pozic přepínačů
      a  volby  z  SW1.  Např.  512  KB: 3(SW1)=OFF; 4(SW1)=OFF; 1(SW2)=ON;
      2(SW2)=OFF až 4(SW2)=OFF.

    Pozdější  verze  PC  (někdy  nazývané  PC-2)  mají  odlišný BIOS, který
interpretuje  přepínač SW2 poněkud odlišně (význam SW1 zůstává stejný).

          SW2 (PC-2)
ON   +1+2+3+4+5+6+7+8+  = 0
     | | | | | | | | |
     | | | | | | | | |  = 1
OFF  +-+-+-+-+-+-+-+-+
      | | | | | | | |   přep.
      | | | | | +-+-+--> 6-8: vždy v OFF
      +-+-+-+-+--------> 1-5: celková RAM: význam stejný jako u PC-1, navíc
                                           je pozice 5 = 512K (v OFF platí)
                                          Maximální kapacita může být 640K.

    Na počítačích PC a XT můžete změnit účinek přepínačů změnou v nastavení
tabulky  vybavení (adresa 0:0410H) a resetováním DOS. Předtím však nastavte
obsah  adresy  0:0472H  na  1234H  (viz zavádění operačního systému, POST),
potom proveďte INT 19H.

    Pokud  během provozu počítače nastane chyba paměti, nebo chcete zjistit
skutečnou velikost paměti, zkuste následující postup: Nastavte přepínače na
malou  velikost  paměti (aby systém fungoval bez chyby), resetujte systém a
po  zavedení  systému  zkuste  příkaz  CHKDSK  k  zjištění,  zda je paměť v
pořádku.  Pokud  ano,  zvětšete nastavení velikosti paměti a opakujte reset
systému  a  kontrolu  paměti.  To opakujte tak dlouho, až bude při kontrole
paměti hlášena chyba.

    Pokud  se  vám  touto  cestou  podaří zvýšit pomocí přepínačů DIL paměť
počítače nad 640K, BIOS bude sice šťastný, avšak DOS tuto operaci nepřežije
(přechodná část COMMAND.COM se načte do nejvyšší části paměti RAM).


    Počítač  AT  nemá nastavování pomocí přepínačů DIL. Konfigurace systému
je nastavena pomocí konfiguračního programu SETUP, který je uložen v paměti
ROM,  výsledek  nastavení  se  uloží  do  paměti  CMOS. Jediné nastavení se
provádí  pomocí  propojovacích  můstků, tyto můstky jsou však již nastaveny
továrně  podle  konkrétního osazení systémové desky a není vhodné je měnit.
Ze  zajímavých  můstků  lze  uvést  pouze  můstek  J18,  který v poloze 1-2
povoluje  použití  druhé části 256K (při 512K na systémové desce), v poloze
2-3  ji  blokuje. Dalším přepínačem AT je přepínač označený jako SW1, který
určuje  inicializační  adaptér  displeje  (pro  inicializační  test POST) v
případě, že data v CMOS jsou neplatná (např. při výpadku baterie). V poloze
ON  (směrem k zadnímu panelu) tento přepínač určuje jako primární grafickou
kartu  CGA,  v poloze OFF (směrem k přednímu panelu) označuje jako primární
grafickou kartu EGA. Nastavení přepínačů karty EGA - viz popis karty EGA.





                    2 . -   Ř a d i č   p ř e r u š e n í




Řadič  přerušení:


Porty 0020H - 003FH: řadič přerušení #1 8259A
---------------------------------------------

    Inicializace řadiče přerušení 8259A:

ICW1: Inic. řídicí slovo - zapisuje se vždy jako první slovo na port 0020H:

        +-+-+-+-+-+-+-+-+
        |7 6 5 4 3 2 1 0|
        +++++++++++++++++ bit
               | |   | +-> 0: nutno nastavit na 1
               | |   +---> 1: 1=jednoduchý mód; 0=kaskádní mód (bude ICW3)
               | +-------> 3: 1=spouštění úrovní; 0=spouštění hranou
               +---------> 4: nutno nastavit na 1

ICW2: Inic. řídicí slovo - zapisuje se bezprostředně po ICW1 na port 0021H:

        +-+-+-+-+-+-+-+-+
        |7 6 5 4 3 2 1 0|
        +++++++++++++++++ bit
         | | | | |         0-2: nepoužito, bity se dosadí automaticky
         +-+-+-+-+-------> 3-7: bity 3 až 7 čísla přerušení INT x

ICW3: Inic.  řídicí  slovo - zapisuje se po ICW2 na port 0021H, pokud byl v
      ICW1 nastaven bit 1 na 0 (=kaskádní mód):

    Řadič je jako MASTER:

        +-+-+-+-+-+-+-+-+
        |7 6 5 4 3 2 1 0|
        +++++++++++++++++ bit
         | | | | | | | |
         +-+-+-+-+-+-+-+-> 0-7: 1=je připojen SLAVE; 0=není SLAVE

    Řadič je jako SLAVE:

        +-+-+-+-+-+-+-+-+
        |7 6 5 4 3 2 1 0|
        +++++++++++++++++ bit
                   | | |
                   +-+-+-> 0-2: číslo SLAVE (kam je připojen k MASTER)


ICW4: Inic. řídicí slovo - zapisuje se po ICW2 resp. po ICW3 na port 0021H:

        +-+-+-+-+-+-+-+-+
        |7 6 5 4 3 2 1 0|
        +++++++++++++++++ bit
         | | | | | | | +-> 0: nutno nastavit na 1
         | | | | | | +---> 1: 1=autom. konec přerušení; 0=použije se EOI
         | | | | | +-----> 2: (pouze pokud je bit 3=1): 1=MASTER; 0=SLAVE
         | | | | +-------> 3: 1=buff. mód; 0=není buff. mód (bit 2 ignor.)
         | | | +---------> 4: 1=spec. režim s úplným vkládání (jen MASTER)
         +-+-+-----------> 5-7: nutno nastavit na 0



    Operační řídicí slova (v běžném provozu):

OCW1: Oper. řídicí slovo - zapisuje se nebo čte z portu 0021H:

        +-+-+-+-+-+-+-+-+
        |7 6 5 4 3 2 1 0|
        +++++++++++++++++ bit
         | | | | | | | |
         +-+-+-+-+-+-+-+-> 0-7: přerušení od vstupu: 1=zakázáno, 0=povoleno

OCW2: Oper. řídicí slovo - zapisuje se na port 0020H:

        +-+-+-+-+-+-+-+-+
        |7 6 5 4 3 2 1 0|
        +++++++++++++++++ bit        (EOI=povel pro konec přerušení)
         | | | | | | | |
         | | | | | +-+-+-> 0-2: úroveň přerušení 0 až 7 (povely 60,C0 a E0)
         | | | +-+-------> 3,4: nutno nastavit na 0
         +-+-+-----------> 5-7: povel: 00=rotace v automat. EOI-nulování
                                       20=nespecifikovaný EOI
         | | |                         40=žádná operace
         | | +>1=automat. mód EOI      60=EOI pro zadanou úroveň (0-7)
         | +-->1=specifik. úroveň 0-7  80=rotace v automat. EOI-nastavení
         +---->1=povel se týká rotace  A0=rotace v nespecifik. módu EOI
                                       C0=nastavení priority (0-7)
                                       E0=rotace ve specif. módu EOI (0-7)





Porty 00A0H - 00BFH: řadič přerušení #2 8259A
---------------------------------------------

00A0H - zápis: vyslání bajtu 20H - signalizace konce přerušení IRQ 8-15
00A1H - zápis/čtení: maskování  přerušení  (bit  0  až  7  = 0 --> povolení
                     přerušení pro vstupy IRQ 8-15)


Hardwarová  přerušení:

    požadavky přerušení řadiče přerušení #1:

IRQ 0    - systémové hodiny (přerušení 18.2 krát za sekundu) (INT 08H)
IRQ 1    - přerušení od klávesnice (INT 09H)
IRQ 2    - zpětný běh EGA, kaskádní požadavek přerušení AT od #2 (INT 0AH)
IRQ 3    - přerušení od sériového portu COM2 (INT 0BH)
IRQ 4    - přerušení od sériového portu COM1 (INT 0CH)
IRQ 5    - tiskárna LPT2, řadič pevného disku XT (INT 0DH)
IRQ 6    - řadič pružných disků (INT 0EH)
IRQ 7    - tiskárna LPT1 (INT 0FH)

            (následující   přerušení   jsou  kaskádně  připojena  k  řadiči
            přerušení #1 přes požadavek IRQ 2)

IRQ 8    - CMOS časovač (1024 krát za sekundu) (INT 70H)
IRQ 9    - (INT 71H)
IRQ 10   - (INT 72H)
IRQ 11   - (INT 73H)
IRQ 12   - (INT 74H)
IRQ 13   - přerušení koprocesory 80287 a 80387 při chybě (INT 02H, INT 75H)
IRQ 14   - řadič pevného disku AT (INT 76H)
IRQ 15   - (INT 77H)


    Nemaskovatelné přerušení NMI (INT 02H) nelze maskovat přímo v porcesoru
pomocí  instrukce  pro  zákaz  přerušení. Proto je umožněno v počítačích PC
maskovat  toto  přerušení  hardwarově  (přerušení  NMI  je  v počítačích PC
generováno při vzniku chyby parity paměti a při vzniku chyby v matematickém
koprocesoru).  U  počítačů  PC/XT  se  povolí  přerušení  vysláním  bajtu s
nastaveným  7.bitem  (=80H)  na  port  00A0H.  Vysláním bajtu s vynulovaným
7.bitem  (=00H)  se přerušení NMI zakáže. U počítače AT se povolí přerušení
vysláním  bajtu s vynulovaným 7.bitem (=00) na port 0070H. Vysláním bajtu s
nastaveným  7.bitem  (=80H hodnoty jsou tedy obráceně než u počítačů PC/XT)
se přerušení NMI zakáže (viz též paměť CMOS - maskování NMI).





                          3 . -   Ř a d i č   D M A


    DMA  (přímý  přístup do paměti) je způsob přenosu dat mezi pamětí a I/O
zařízením  bez  účasti  procesoru.  Tento  způsob  přenosu  se používá při
požadavku  rychlého  přenosu velkého množství dat, jako je např. přenos dat
mezi pamětí a disketovou jednotkou nebo pevným diskem.

    Původní  PC  podporoval  čtyři  8-bitové  kanály  DMA,  přes  20-bitový
adresový prostor, s použitím řadiče DMA Intel 8237A.

   +---------+------------------------------------------------+
   |kanál DMA|               použití v PC a XT                |
   +---------+------------------------------------------------+
   |   0     |      občerstvování paměti (nejvyšší priorita)  |
   |   1     |      nepoužit                                  |
   |   2     |      adaptér disketové jednotky                |
   |   3     |      adaptér pevného disku (nejnižší priorita) |
   +---------+------------------------------------------------+

    Systém  DMA počítačů AT je založen pro zvýšení kompatibility na systému
DMA  počítačů  PC a XT. Ke čtyřem 8-bitovým kanálům DMA počítačů PC přidává
AT  druhý  řadič  DMA  8237A-5, který podporuje kanály 4-7 (čtyři 16-bitové
kanály).

   +---------+------------------------------------------------+
   |kanál DMA|               použití v AT                     |
   +---------+------------------------------------------------+----------+
   |   0     |      volný                                     |          |
   |   1     |      řízení synchronní datové linky SDLC       | 8-bitové |
   |   2     |      adaptér disketové jednotky                |  kanály  |
   |   3     |      adaptér pevného disku                     |          |
   +---------+------------------------------------------------+----------+
   |   4     |      (řadič 2) kaskáda pro řadič 1             |          |
   |   5     |      volný                                     | 16-bitové|
   |   6     |      volný                                     |  kanály  |
   |   7     |      volný                                     |          |
   +---------+------------------------------------------------+----------+



Porty 0000H - 0007H: bázové adresy DMA a offsetové registry
-----------------------------------------------------------

    Všechny  registry jsou 16-bitové. Nejdříve se čte/zapisuje nižší bajt a
potom  na  stejné  adrese  portu  vyšší bajt (viz též port 000CH - nulování
klopného  obvodu ukazatele bajtů). Bázové adresy jsou offsetovány v stránce
DMA.

0000H - zápis: bázová adresa kanálu 0 DMA (též nastaví současnou adresu)
        čtení: současná adresa kanálu 0 DMA          (občerstvování)
0001H - zápis: bázová adresa a čítač slov kanálu 0 DMA     "
        čtení: současný stav čítače slov kanálu 0 DMA      "
0002H - zápis: bázová adresa kanálu 1 DMA
        čtení: současná adresa kanálu 1 DMA
0003H - zápis: bázová adresa a čítač slov kanálu 1 DMA
        čtení: současný stav čítače slov kanálu 1 DMA
0004H - zápis: bázová adresa kanálu 2 DMA            (disketová jednotka)
        čtení: současná adresa kanálu 2 DMA                "
0005H - zápis: bázová adresa a čítač slov kanálu 2 DMA     "
        čtení: současný stav čítače slov kanálu 2 DMA      "
0006H - zápis: bázová adresa kanálu 3 DMA            (pevný disk)
        čtení: současná adresa kanálu 3 DMA                "
0007H - zápis: bázová adresa a čítač slov kanálu 3 DMA     "
        čtení: současný stav čítače slov kanálu 3 DMA      "



Porty 00C0H - 00CFH: bázové registry 16-bitového DMA
----------------------------------------------------

    Kanály  0-3  přenosu  DMA  pracují s 8-bitovým přenosem dat (standardní
PC).  U  počítačů  AT jsou doplněny kanály 4-7 podporující 16-bitový přenos
dat.  Přenos pro tyto kanály začíná vždy na hranici slov a všechny adresy a
čítače  pracují  pro 16-bitová slova (např. bázová adresa 0123H se aktuálně
vztahuje na offset 0246H od začátku stránky v příslušném kanálu).

00C0H - zápis: bázová a současná adresa kanálu 4 DMA (bity 1-16; bit0=0)
        čtení: současná adresa kanálu 4 DMA
00C2H - zápis: čítač slov kanálu 4 DMA
        čtení: současný stav čítače slov kanálu 4 DMA
00C4H - zápis: bázová a současná adresa kanálu 5 DMA (bity 1-16; bit0=0)
        čtení: současná adresa kanálu 5 DMA
00C6H - zápis: čítač slov kanálu 5 DMA
        čtení: současný stav čítače slov kanálu 5 DMA
00C8H - zápis: bázová a současná adresa kanálu 6 DMA (bity 1-16; bit0=0)
        čtení: současná adresa kanálu 6 DMA
00CAH - zápis: čítač slov kanálu 6 DMA
        čtení: současný stav čítače slov kanálu 6 DMA
00CCH - zápis: bázová a současná adresa kanálu 7 DMA (bity 1-16; bit0=0)
        čtení: současná adresa kanálu 7 DMA

Porty 0080H - 008FH: stránkové registry DMA 74LS612
---------------------------------------------------

    Chcete-li nastavit počáteční adresu operací DMA, vyberte nejdříve kanál
tím,  že  provedete instrukci OUT (hodnota 00H až 0FH) na stránkový registr
(porty  0081H  -  0083H)  a  potom  nastavíte bázovou adresu (porty 0000H -
0007H) pro příslušný kanál. Stránkový registr se nastaví 4-bitovou hodnotou
reprezentující bity 16-19 20-bitové adresy DMA. Protože běžná adresa čítače
DMA  je  16-bitová  hodnota,  není  možné  provádět  pomocí DMA přenos přes
hranice 64K (tj. adresy 1000:0000, 2000:0000 atd.).

0081H - stránkový registr kanálu 2 - adresové bity 16-19 (disketový DMA)
0082H - stránkový registr kanálu 3 - adresové bity 16-19 (pevný disk)
0083H - stránkový registr kanálu 1 - adresové bity 16-19

    Počítače  AT  používají  pro  nastavení  adresy  stránky  všech  8 bitů
stránkového registru. Je to z toho důvodu, že AT používá 24-bitový adresový
prostor.  Spodních  16  bitů  je nastaveno v adresovém registru kanálu DMA,
vyšších 8 bitů je použito ze stránkového registru. Velikost stránek je 128K
(tj  64K  slov),  takže  přenosy  DMA nesmějí překračovat hranici 128K (tj.
adresy 2000:0, 4000:0 atd.).

0081H - stránkový registr kanálu 2 - adresové bity 16-23 (disketový DMA)
0082H - stránkový registr kanálu 3 - adresové bity 16-23 (pevný disk)
0083H - stránkový registr kanálu 1 - adresové bity 16-23 (SDLC)
0087H - stránkový registr kanálu 0 - adresové bity 16-23
0089H - stránkový registr kanálu 6 - adresové bity 17-23
008BH - stránkový registr kanálu 5 - adresové bity 17-23
008AH - stránkový registr kanálu 7 - adresové bity 17-23
008FH - refresh

    Stránkový  registr  na  adrese  0080H má u počítače AT zvláštní funkci.
SLouží   jako   diagnostický  bod  a  jsou  do  něj  střádány  chyby  během
inizializačního testu POST.

Porty 0040H - 005FH: časovač 8253-5 (AT: 8254.2)
------------------------------------------------

    Časovač  používá  svůj  vlastní  krystal o kmitočtu 14.31818 MHz, jehož
kmitočet  po  vydělení  předděličkou  (dělící  v  poměru  1:12) na kmitočet
1.193182úMHz  slouží  jako  zdroj  hodinových impulsů časovače (vstup CLK).
Funkce  8254.2  u  AT  se liší oproti 8253 především větším počtem příkazů,
které  umožňují  snadnější  zapamatování stavu čítače během čítání a zpětné
čtení.

0040H -  zápis: nastavení čítače 0
         čtení: stav čítače 0

          Výstup  z  čítače 0 je přiveden na vstup IRQ 0 řadiče přerušení a
používá se jako zdroj impulsů pro systémové hodiny (dělící poměr 65279).

0041H -  zápis: nastavení čítače 1
         čtení: stav čítače 1

          Čítač  1  slouží  ke generování signálu REFRESH pro občerstvování
         paměti (dělící poměr 4866).

0042H -  zápis: nastavení čítače 2
         čtení: stav čítače 2

          Výstup z čítače 2 je použit jako výstup na vestavěný reproduktor.
         Výstup  na  reproduktor se aktivuje pomocí portu 0061H (bity 0 a 1
         musí být nastaveny na 1).

              mov       bx,330         ; VSTUP - frekvence uvedená v Hz
              mov       cx,40000       ; VSTUP - prodleva (pomocný údaj)
              mov       al,0b6h        ; povel pro nastavení kanálu 2
              out       [43h],al       ; nastavení povelu
              mov       dx,12h         ; vyšší slovo konstanty
              mov       ax,34deh       ; nižší slovo konstanty
              div       bx             ; výpočet dělícího poměru
              out       [42h],al       ; nastavení nižšího bajtu děličky
              mov       al,ah          ; vyšší bajt děličky
              out       [42h],al       ; nastavení vyššího bajtu děličky
              in        al,[61h]       ; současné nastavení portu 61h
              or        al,3           ; nastavení bitů pro reproduktor
              out       [61h],al       ; zapnutí zvukového výstupu
              loop      $              ; prodleva
              and       al,0fch        ; vynulování ovládacích bitů
              out       [61h],al       ; vypnutí zvukového výstupu

0043H -  zápis: volba módu čítače (čtení registru u 8253 není možné)

        +-+-+-+-+-+-+-+-+
        |7 6 5 4 3 2 1 0|
        +++++++++++++++++  bit
         | | | | | | | +->  0:  1=čítá v kódu BCD, 0=čítá v binárním kódu
         | | | | +-+-+---> 1-3: mód čítače:  000 - mód 0     (při práci
         | | | |                             001 - mód 1      s pomocným
         | | | |                             x10 - mód 2      registrem
         | | | |                             x11 - mód 3      jsou tyto
         | | | |                             100 - mód 4        bity
         | | | |                             101 - mód 5      bezvýznamné)
         | | +-+---------> 4-5: 00 - operace   s  pomocným  registrem  (při
         | |                         čtení  stavu  čítače  se okamžitý stav
         | |                         čítače  uschovává v pomocném registru,
         | |                         aby   jej   bylo   možno  přečíst  bez
         | |                         zastavení čítače)
         | |                    01 - čtení/zápis jen nižší slabiky děliče
         | |                    10 - čtení/zápis jen vyšší slabiky děliče
         | |                    11 - čtení/zápis nižší a potom vyšší slab.
         +-+-------------> 6,7: volba čítače: (0 až 2, 3=neplatný kód)

         MÓD 0 - přerušení  na  konci  čítání:  Výstup  OUT  čítače  se  po
                 ukončení  čítání  překlopí  z  hodnoty L na úroveň H až do
                 doby  nového  nastavení.  Při  zápisu  předvolby v průběhy
                 čítání se po zápisu 1. slabiky probíhající čítání zastaví,
                 po zápisu 2. slabiky se odstartuje nové čítání. Vstup GATE
                 (pouze u čítače 2 - bit 0 portu 61h) povoluje čítání pouze
                 pokud je na úrovni H.
         MÓD 1 - monostabilní generátor: Vzestupná hrana vstupu GATE spustí
                 výstupní  impuls - výstup OUT přejde na úroveň L a zůstane
                 v ní po dobu nastavenou předvolbou. Po této době se výstup
                 navrátí  zpět  na  úroveň  H.  Jestliže byla během impulsu
                 vložena nová předvolba, délka impulsu se nezmění (změní se
                 až následující impuls). Průběžný stav čítače může být čten
                 kdykoliv,  aniž by to ovlivnilo generování impulsu. Impuls
                 je možné znovu spouštět i v době jeho trvání.
         MÓD 2 - dělení  frekvence:  Výstup  OUT  bude  na úrovni L po dobu
                 jedné   periody   hodinového   impulsu  CLK,  rozteč  mezi
                 výstupními  impulsy  odpovídá  době  nastavené  předvolbou
                 čítače  (výstupní  kmitočet  OUT  je tedy N-krát menší než
                 hodinový kmitočet CLK). Jestliže byl obsah registru čítače
                 změněn mezi dvěmi výstupními impulsy, probíhající výstupní
                 perioda  se nezmění. Vstup GATE an úrovni L převede OUT na
                 úroveň  H.  Vzestupná hrana GATE zahájí čítání z počáteční
                 hodnoty  (lze  využít  k  synchronizaci čítače). Výstup je
                 také  neaktivní  (tj. na úrovni H) po dobu plnění registru
                 čítače předvolbou.
         MÓD 3 - generování  obdélníkových  průběhů:  Mód  3 je stejný jako
                 módú2  s  tím  rozdílem, že výstup OUT bude na úrovni L po
                 polovinu  doby  a na úrovni H po druhou polovinu doby. Pro
                 liché číslo N (předvolba) bude OUT o 1 takt déle na úrovni
                 H.  Nová hodnota děliče se uplatní již při dalším půltaktu
                 výstupu OUT.
         MÓD 4 - strobování ovládané programem: Po nastavení módu je OUT=H,
                 po  zavedení  předvolby  začne  čítat,  po dočítání přejde
                 výstup  OUT  po dobu jedné periody CLK na úroveň L a vrátí
                 se zpět na úroveň H. Vstup GATE=L zastaví čítání.
         MÓD 5 - strobování   oládané  obvodově:  Čítač  zahájí  čítání  po
                 vzestupné  hraně  vstupu  GATE  (tj.  přechod L -> H) a po
                 dočítání  přejde  výstup  OUT po dobu jedné periody CLK na
                 úroveň  L.  Nová  vzestupná  hrana  GATE  zahájí čítání od
                 počáteční hodnoty i během čítání.

Pozn.: Zápis  hodnoty  0  jako  časovací  konstanta  odpovídá  hodnotě  216

0064H - povelový registr klávesnice AT (pouze pro AT !)
      - tento  port komunikuje s 8042, který spouští řídící program on-chip
        pro obsluhu klávesnice. Přijímá kódy povelů a datové bajty.


    Klávesnice   AT  (a  její  mikropočítačový  interface  Intel  8042)  je
programovatelná  a  je  mnohem  zajímavější  než  klávesnice  PC ve "starém
stylu".  S  použitím  následujících  informací  můžete  nastavovat rychlost
opakování klávesy a hrát hry s použitím indikátorů LED na klávesnici.

    Port  60H  je  určen  pro zápis dat a je podporován pro kompatibilitu s
dřívějšímy  modely.  Pokud  příklad  používající  port 64H nebude pracovat,
zkuste použít port 60H.

    Port  64H je určen pro zápis povelů a dat a pro čtení stavu klávesnice.
Před  vysláním  povelu  na  klávesnici testuje BIOS její stav (IN AL,64H) a
ubezpečuje  se, že není stisknuta žádná klávesa nebo že vnitřní buffer není
plný atd. Je v tom malý risk, pokud jdete přímo a vyšlete povel:

         mov       al,kod_cmd               ; číslo povelu pro klávesnici
         out       64h,al                   ; vyslání povelu



    Pro dvoudílné povely, jako např. nastavení rychlosti opakování klávesy,
je rozumné zařadit mezi jednotlivé výstupy malou prodlevu:

         out       64h,al                   ; vyslání povelu
         mov       cx,2000h                 ; prodleva asi 10ms
prodl:   loop      prodl                    ; prodleva mezi výstupy OUT
         mov       al,hodnota_dat           ; druhá část povelu pro kláv.
         out       64h,al                   ; vyslání druhé části povelu

    Třídy  počítačů AT obsahují hodiny reálného času napájené z vestavěných
baterií  a  64-bajtovou  nízkopříkonovou  paměť  CMOS  (tato  paměť  je při
vypnutém počítači napájena též z baterií).

    Paměť  CMOS  obsahuje  různé  informace,  včetně  běžného  času a data,
nastavení  hardwarové  konfigurace  a  stavový bajt pro uzavření (uzavírací
bajt  se  používá  v mechanismu umožňujícím AT opakovaně startovat v místě,
kde procesor program k ukončení ochranného módu).

    Pokud  uvidíte  během inicializačního testu POST hlášení "Run Setup" je
to proto, že některý hardware nemá uložen svůj záznam konfigurace nebo se v
CMOS RAM vyskytly nějaké jiné problémy.


Porty 0070H - 0071H: přístup k paměti CMOS, maskování přerušení NMI
-------------------------------------------------------------------

0070H - zápis: nastavení adresy CMOS (Bity 0 až 5: adr. 0 až 63; bit7: NMI)

        U   počítače   AT   slouží   tento   port   současně   k  maskování
        nemaskovatelného  přerušení  NMI.  Jakýkoliv výstup na tento port s
        vynulovaným  bitem  číslo  7 umožňuje nemaskovatelné přerušení NMI;
        nastavení  tohoto  bitu  způsobí  zákaz  přerušení  NMI  (Maskování
        přerušení NMI u počítače PC/XT - viz kapitola řadič přerušení).

0071H - zápis: zápis dat do CMOS na adresu nastavenou pomocí OUT 70H,adr
        čtení: čtení dat z CMOS z adresy nastavené pomocí OUT 70H,adr

    Ke  čtení  bajtu  z  paměti  CMOS vyšlete nejdříve na port o adrese 70H
adresu  paměťového  místa  CMOS,  které  má  být čteno nebo do kterého bude
zapisováno,  potom  z  adresy  71H můžete číst nebo na ni zapisovat data do
CMOS na uvedené adrese.

Příklad:                               ; čtení typu pevného disku
         mov       al,12h              ; adresa údaje o disku = 12H
         out       70h,al              ; nastavnení adresy CMOS na 12H
         jmp       $+2                 ; malá prodleva k ustálení dat CMOS
         in        al,71h              ; AL nyní obsahuje typ pevného disku

    Adresy  10H  až  20H jsou chráněny metodou kontrolního součtu, aby bylo
možné  detekovat,  když  jsou  baterie  vybité  nebo  byl  do paměti zapsán
neplatný  zápis  konfigurace  (např. když se "zaběhne" program a náhodou se
provede instrukce OUT 71H - obvykle se změní nastavení pevného disku, které
bylo  čteno  naposled).  Kontrolní  součet  je  jednoduchý 16-bitový součet
chráněných bajtů.

    Pozn.: Další  informace  o  hodinách  reálného  času získáte v příručce
           Motorolla MC146818.

        +-+-+-+-+-+-+-+-+
        |7 6 5 4 3 2 1 0|
        +++++++++++++++++ bit
         | | | | | | | +-> 0: možné uložení denního cyklu (0=standard) (0)
         | | | | | | +---> 1: cyklus: 0=12; 1=24                       (1)
         | | | | | +-----> 2: mód dat BCD: 1=binární; 0=BCD            (0)

       - stavové bity příznaků přerušení

0DH    - stavový registr hodin reálného času - D (zápis)
       - bit 7 = 1 pokud CMOS=RAM je připojena k napájení
               = 0 idnikuje, že baterie je vybitá

0EH    - stavový bajt diagnostiky při vnitřní inicializaci systému (POST)
         tento bajt ukládá POST při inicializaci systému

        +-+-+-+-+-+-+-+-+
        |7 6 5 4 3 2 1 0|
        +++++++++++++++++ bit
         | | | | | | | +-> 0: = 0
         | | | | | | +---> 1: = 0
         | | | | | +-----> 2: 1=čas neplatí (např. není 30.únor)
         | | | | +-------> 3: 1=špatný pevný disk (nelze z něj zavést OS)
         | | | +---------> 4: 1=velikost paměti není správná
         | | +-----------> 5: 1=záznam konfigurace není správný
         | +-------------> 6: 1=kontrolní součet CMOS RAM nesouhlasí
         +---------------> 7: 1=vybitá baterie CMOS RAM

0FH    - stavový bajt přerušení
         Tento  bajt  je čten při startu počítače po resetu procesoru kvůli
         správnému  určení,  zda  byl  reset  použit jako cesta k přerušení
         procesoru 80286 z ochranného módu.
              0 = měkký reset (Ctrl-Alt-Del) nebo nevyjímečné přerušení
              1 = přerušení po určení velikosti paměti
              2 = přerušení po provedení testů paměti
              3 = přerušení po chybě paměti (kontrola parity 1 nebo 2)
              4 = přerušení s požadavkem zavaděče systému
              5 = přerušení  instrukcí  FAR JMP (restart vnitřního řadiče a
                  skok na adresu 0:[0467H])
          6,7,8 = přerušení po provedení testu ochranného módu
              9 = přerušení po provedení blokového přesunu (INT 15H/sl.87H)

je  vhodné  ponechat  ovládání  pevného disku na systémovém firmware, které
zamaskuje odlišnosti mezi jednotlivými řadiči pevných disků.


    Řadič  pevného  disku  počítače  XT  dekóduje porty 320H až 327H. Řadič

přiřazeno  jako  méně používané přerušení IRQ pro LPT2). INT 0DH zakáže DMA
pevného disku a navrátí řízení.

    Tento  popis  se  vztahuje k řadiči pružných disků (FDC), jehož hlavním
prvkem je NEC ćPD765 (nebo kompatibilní čip FDC).

    Řadič  pružných disků počítače AT je umístěn na stejné kartě jako řadič
pevného  disku, avšak jinak je kompatibilní se standardním řadičem pružných
disků  počítačů PC/XT (kromě několika poznámek uvedených dále). Mezi hlavní
rozdíly  patří především to, že řadič pružných disků počítače AT je schopen
vícenásobných  rychlostí  přenosu  dat, avšak obsluhuje pouze dvě disketové
mechaniky.

    - řadič pružných disků 1 dekóduje porty 03F0H až 03F7H
    - řadič pružných disků 2 dekóduje porty 0370H až 0377H (pouze AT)

    Řadič   pružných   disků  generuje  po  každé  operaci  (čtení,  zápis,
vystavení,  rekalibrace,  atd.)  přerušení  úrovně  6  (IRQ  6),  které  je
vektorováno na INT 0EH a obsluhováno BIOSem.

-------------------------------------------

označení disketových mechanik A na C a B na D).

          | | | | | +----->  2:  0=reset řadiče disket; 1=uvolnění řadiče
          | | | | +------->  3:  1=možný přenos DMA disket a přerušení

        +++++++++++++++++  bit

                        - číslo hlavy (strany)
                        - číslo sektoru
                        - délka sektoru

Porty 03D0H - 03DFH: port grafické karty CGA
--------------------------------------------

    CGA  je barevný grafický adaptér (Color/Graphics Adapter CGA). Grafická
karta  CGA  je  vystavěna  kolem  integrovaného grafického řadiče Motorolla
6845 (CRT controller chip).

       1 0 . -   G r a f i c k á   k a r t a   E G A   ( a   M D A )

    Grafická  karta  EGA  (Enhanced  Graphics  Adapter)  je  kompatibilní s
kartami  CGA  (Color/Graphics  Adapter) a MDA (Monochrome Display Adapter),
avšak má mnoho dalšího vybavení, které ji předurčuje k použití v nejširších
aplikacích.

    Mezi její přednosti patří:

    - vyšší rozlišitelnost v textových i grafických režimech
    - grafické módy na monochromním monitoru
    - softwarově definovatelné fonty znaků v textových módech
    - společné zobrazení více fontů najednou
    - 64 barev v textových nebo grafických módech
    - jemné rolování obrazu (bodové rolování)
    - hardwarově řízeno rozdělení obrazovky
    - do videopaměti je možné zapisovat bez nebezpečí "sněžení" obrazu

    EGA dekóduje porty ve dvou oblastech:

    EGA #1 dekóduje porty 03C0H až 03DFH (kvůli slučitelnosti s kartou CGA)
    EGA #2 dekóduje porty 02C0H až 02DFH (druhá karta EGA v systému)

    Pro slučitelnost s graf. kartou MDA dekóduje EGA porty 03B0H - 03BFH


    EGA  generuje  na začátku vertikálního zpětného běhu přerušení úrovně 2
(IRQ  2),  které  má  nastaven vektor přerušení INT 0AH. Při použití tohoto
přerušení  mějte  na mysli, že AT používá IRQ 2 jako kaskádní požadavek pro
celou třídu přerušení (IRQ 8-15).

Pozn.: BIOS  ukládá  obraz  hodnot  nastavení  registrů řadiče CRT a jiných
       informací EGA do datového prostoru EGA. Pokud chcete změnit některou
       hodnotu  nastavenou  na  portu,  přečtěte hodnotu uloženou v tabulce
       proměnných karty EGA, nastavte bit, proveďte výstup na port a uložte
       do proměnné novou hodnotu.

Port 0201H: port herního I/O adaptéru (joystickový port)
--------------------------------------------------------

    Port 0201H je označen jako port herního adaptéru nebo joystickový port.
Není  podporován  modulem  ROM-BIOS počítačů PC/XT, ale BIOS AT - přerušení
INT 15H/služba 84H umožňuje snadné použití interface pro tento adaptér.

    Jde  především  o  analogově/digitální konvertor, který může být použit
vědeckými  měřícími přístroji a jinými zařízeními, která obsahují analogový
(odporový)  vstup  na  interface. Umožňuje použít až čtyři číslicové vstupy
(data  zap/vyp,  jako  je  např. stisk tlačítka) a až čtyři odporové vstupy
(jako  jsou  X-souřadnice  joysticku  nebo hodnota teploty z elektronického
teploměru).

    Hodnota obdržená instrukcí IN z portu 0201H má strukturu:

        +-+-+-+-+-+-+-+-+
        |7 6 5 4 3 2 1 0|
        +++++++++++++++++ bit
         | | | | | | | +-> 0: Ax -+
         | | | | | | +---> 1: Ay  +-> souřadnice (odporové, časově
         | | | | | +-----> 2: Bx  |               závislé vstupy)
         | | | | +-------> 3: By -+
         | | | +---------> 4: A1 -+
         | | +-----------> 5: A2  +-> tlačítka/spouštění (číslicové vstupy)
         | +-------------> 6: B1  |
         +---------------> 7: B2 -+

    Označení:  A=joystick  A;  B=joystick  B; x,y = souřadnice X a Y; 1,2 =
               tlačítka joysticku 1 a 2.

    Vstupy z tlačítek (digitální vstupy) můžete číst tímto způsobem:

         mov       dx,201h             ; adresa portu
         out       dx,al               ; inicializace řízení (AL=cokoliv)
         in        al,dx               ; čtení bitů 4-7 tlačítek (0=stisk)

    Joysticky,  ovladače,  měřící  přístroje  (odporové  vstupy) jsou čteny
měřením  doby,  po  kterou  jsou  bity  X  nebo Y po instrukci OUTú0201H,xx
nastaveny na hodnotu 1.

    Čtení samostatných odporových vstupů (příklad - souřad. X joysticku A):

         mov       dx,0201h            ; adresa portu
         out       dx,al               ; inicializace řízení (AL=cokoliv)
         mov       cx,-1               ; nastavení čítače odporu
opet:    in        al,dx               ; čtení nastavení
         inc       cx                  ; čítač
         test      al,1                ; přešel již bit souřadnice X na 0 ?
         jnz       opet                ; čekání dokud je bit souř. X = 1

    Hodnota  prodlevy  nastřádaná  v  registru  CX  bude  indikovat  pozici
souřadnice X joysticku A. Tato hodnota je relativní a závisí na koeficientu
převodu  celého převodního řetězce, tj. převodu polohy na interval a měření
délky intervalu. Pro přesnější převod je lepší použít hardwarového časovače
(odtraní i vliv přerušení na převod).

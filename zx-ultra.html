MD.js Ultra 🧊 / ZX Spectrum 48K

feature/zx-ultra · 48K BASIC ROM · Vanilla JavaScript · MIT CPU

Jak to funguje?

1. Stiskni Start ZX. 2. Klikni na obrazovku, aby klávesnice ovládala Spectrum. 3. V režimu Fullscreen Workbench otevři .sna, .tap nebo vlastní .rom. 4. Pro standardní TAP vlož kazetu, pak na ZX zadej LOAD "".

Rozsah: MinZX poskytuje 48K CPU+obrazovku+zvuk a SNA. TAP podporuje experimentální ROM fast-load, ne turbo-loader kazety. Fullscreen nabízí CPU registry, RAM, ASM Lite editor a SNA snapshoty. Plný debugger, TZX a .Z80 snapshoty zatím nepodporujeme.

Markdown integrace

~~~zx
model: 48k
rom: local-zx48
~~~

Renderuj Markdown běžně přes new MD({mode:'extended'}).mount(article, source) a potom zavolej MDZX.enhance(article). Markdown jen připraví vložení; emulátor nespustí kód před kliknutím uživatele.

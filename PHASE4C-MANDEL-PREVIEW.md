## How to run

1. Open `optional/pc/index.html`.
2. Choose `AT / 80286`, enable checkbox `80287XL (preview)` and choose `VGA`. Common CPU/FPU clock: 12 or 16 MHz (nominal only).
3. Wait for FreeDOS prompt `A:\>`.
4. Enter `MANDEL` and press Enter. Fractal is generated by guest x87 instructions. Press a key to return to DOS text mode.
5. XT / 8088 profile still has NO 80287XL. In default AT profile the FPU is OFF until enabled.

## Important technical limitation

The provided C++ references distinguish 80-bit x87 extended precision and special values. JavaScript's Number offers 53 significant binary digits, not 64, and lacks hardware x87 instruction cycles and exact exception/rounding semantics. This educational subset **must not be labeled full 80287XL**. For full FPU gate: BigInt-backed 80-bit significand/exponent, advanced instructions, exception masks, save/restore, wait/busy integration, signed edge-case and golden-vector tests.

No raw historical ROMs and no C++ code are built as runtime modules. Supplied binary/ROM/FAT12 media remain PERSONAL; public redistribution rights of included user-provided assets remain to be reviewed. The upstream DOSBox-X commit for FPU references is unverified.

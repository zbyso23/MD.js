# MiniChem Plus I / v5.4.4

Offline chemical typesetting subset; not full mhchem.

Supports isotope notation `^{14}C`, `^{235}_{92}U`, ionic charges `Fe^{3+}`, `SO4^2-`, hydrate separator `*` or `·` and physical state markers `(s)`, `(l)`, `(g)`, `(aq)`. Existing Basic formulas and arrows retained. No arrow annotations, chemistry calculations or balancing.

Test with `node optional/math/minichem-plus1.test.cjs` and existing KaTeX / Basic tests.
